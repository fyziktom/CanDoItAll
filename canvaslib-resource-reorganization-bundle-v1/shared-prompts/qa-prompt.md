# QA Prompt

Validate the current subbundle as a senior C# / Blazor / Canvas reviewer.

- Verify the exact files listed in the subbundle source references.
- Confirm the resulting folder structure is logical and the ownership lines are obvious.
- Confirm the generated include components match the manifest order.
- For runtime or calendar changes, require browser truth on the target route before passing the gate.
- Fail the subbundle if any CanvasLib file still exceeds 2000 lines when that subbundle claims to close a size hotspot.
- Record concrete proof only: commands, route checks, screenshots, or line-count output.
