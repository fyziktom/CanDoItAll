# Implementation Prompt

Implement one bundle subbundle at a time.

- Read the root `README.md`, `plan/01-phase-plan.md`, the selected subbundle README, and `traceability/01-requirement-traceability.md` first.
- Do not start code before the prerequisite gate for the selected subbundle is satisfied.
- Keep changes minimal and canonical to the existing process module.
- Preserve strong typing. Do not route branch behavior through free-text-only logic.
- Update the bundle status, execution report rows, and proof notes while the work is fresh.
- If proof exposes a weak earlier foundation, reopen that subbundle instead of pushing forward.
