# Normalized Requirements

- `RQ-01`: Playwright MCP must be proven working again in the elevated session before the bundle proceeds.
- `RQ-02`: The structure canvas must be tested through real MCP interactions for adding multiple node types.
- `RQ-03`: The structure canvas must be tested through real MCP interactions for right-click menus, context actions, and related canvas UI surfaces.
- `RQ-04`: The structure canvas must be tested through real MCP interactions for links, dependencies, and nearby graph behaviors.
- `RQ-05`: Any discovered regression must be routed into scoped repair work and revalidated before closure.
- `RQ-06`: The bundle must close with screenshot-backed browser analytics and completed-stage validation.
- `RQ-07`: Overlapping or exploded project-structure layouts must be repairable through a logical recomposition path instead of being left as unreadable saved state.
- `RQ-08`: The repaired layout must persist on reload and remain readable when judged as a real project mindmap, not only as a raw collision-free geometry output.
- `RQ-09`: A fresh managed SQLite profile under `artifacts` must be used for the canonical-bundle validation run instead of reusing an older profile.
- `RQ-10`: `candoitall-canonical-architecture-review-bundle-v2` must be reconstructed into project structure as an umbrella project plus properly titled and coded subprojects with best-guess timespans.
- `RQ-11`: AI agents must exist both in project-structure execution lanes and in the canonical CRM/HR AI-agent directory for the fresh validation profile.
- `RQ-12`: The umbrella and all subproject mindmaps must be reviewed through real Playwright MCP browser proof with screenshots.
- `RQ-13`: The resulting umbrella plus subproject plans must be judged from a senior project-manager perspective for execution controllability.
- `RQ-14`: If any remaining readability or interaction gap is not worth blocking closure, it must be recorded as the next phase of this bundle rather than hidden as an implicit risk.
