# Structured Input

- Scope:
  - real Playwright MCP validation of the project-structure canvas
  - node creation across multiple node families
  - context-menu and right-click interaction coverage
  - connections and dependency behavior coverage
  - repair execution if failures are discovered
- Explicit quality bar:
  - use a headed real browser through MCP
  - capture screenshots and browser analytics
  - keep failures tied to scoped repair work instead of loose notes
- Out of scope unless a failure forces expansion:
  - speculative Workbench redesign
  - unrelated CRM/HR or non-canvas flows
