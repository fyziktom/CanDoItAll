# Glossary

- **worldY**: normalized vertical harmony position in [0..1] (0=bright/up, 1=dark/down).
- **xIndex**: integer timeline position (history and future steps).
- **lane**: additional vertical offset for parallel suggestion paths.
- **module**: a C# component that provides optional signals for planning (patterns, style inference, etc.).
- **widget**: an in-canvas UI panel for a module (controls + status + tooltips).
- **novelty penalty**: scoring penalty discouraging repetitive loops.
- **pattern corpus**: curated chord progressions from public-domain sources, stored as normalized token sequences.
