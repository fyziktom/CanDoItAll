This zip contains prompts (English) intended for Codex to fix the current MusicXML + MIDI recording issues in your Blazor WASM notation editor.

Recommended workflow
1) Paste 00_START_PROMPT.txt into Codex.
2) Then run prompts in order 01..04 as separate Codex runs (or keep them as milestones in one run).

Included fixtures
- The fixtures/ folder contains MusicXML snippets used by the test prompt.
- Codex should copy them into tests/MusicTheory.Tests/Fixtures/MusicXml/ inside the repo.

All source code comments must be in English.
