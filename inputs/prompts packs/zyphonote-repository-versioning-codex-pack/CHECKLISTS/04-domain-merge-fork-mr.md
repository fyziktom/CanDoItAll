# Merge / fork / MR checklist

- [x] Score compare returns semantic hunks, not only raw text diffs.
- [x] Playlist/package/event merges use stable keys.
- [x] Merge preview exposes conflict hunks.
- [x] Fork policy defaults are safe for private planning content.
- [x] Non-owner forks are blocked from instant marketplace listing/publication.
- [x] Merge request mergeability is rechecked at merge time.
- [x] Merge requests store source/target head hashes and merge base.
