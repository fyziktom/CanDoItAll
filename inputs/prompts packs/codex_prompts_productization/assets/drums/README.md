# Drum sample assets

This prompt bundle includes a tiny **synthetic CC0** drum kit under `assets/drums/synthetic_cc0/`:
- kick.wav
- snare.wav
- hihat_closed.wav
- hihat_open.wav

These are intended as a safe, lightweight default kit for offline-first PWA.

## Recommended external upgrade (optional)
If you want more realistic drum machine samples, consider using a **Public Domain** kit from the “Sampled” dataset by Oramics:
- Example kit page (license shown as Public Domain): https://oramics.github.io/sampled/DM/LM-2/

Implementation guidance in prompt `08_DRUM_GENERATOR_AUDIO_AND_LIBRARY.md` recommends making external kits optional (and ideally gitignored) to keep repo size small.
