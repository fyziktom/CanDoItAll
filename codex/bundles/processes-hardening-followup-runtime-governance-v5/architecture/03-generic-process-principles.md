# Generic Process Principles

The process core must not assume software delivery.

## Generic Operation Types

- read context
- read upstream artifacts
- produce process artifacts
- mutate declared target
- validate target
- capture proof
- make decision
- perform external action
- recover artifacts

These map to many domains:

- business planning
- legal review
- purchasing
- manufacturing QA
- HR onboarding
- incident response
- software delivery
- research workflows

## Domain-Specific Details

Domain-specific details belong in:

- process templates
- skills
- role instructions
- artifact validation plugins
- workflow executors

They should not be hardcoded into the process runtime core.
