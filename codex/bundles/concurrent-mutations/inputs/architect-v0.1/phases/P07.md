# P07 · Workflow and Process resume/publication integration

Status: **Proposed — not started or validated.**

## Goal
Integrate proven basis, approval and effect semantics into the largest long-running execution paths without weakening existing governance.

## Dependencies and entry evidence
Dependencies: P04, P06.

- The smaller real governed pilot and relevant external/owner semantics are proven; Process UI extraction boundaries refreshed.

## Included changes
- Map definition versions, prepared launches, checkpoints, approvals, claims and owner effect receipts to the new semantic vocabulary.
- Keep immutable execution snapshots valid while revalidating publication into current mutable targets.
- Define legacy checkpoint/basis handling, cancellation/takeover fences, replay denials and compensation behavior.
- Update process/workflow UI, tool schemas and recovery operator paths together.

## Explicit exclusions
- No unrelated rewrite of the process engine or hard worker-isolation project.
- No auto-upgrading old approvals by inventing current input provenance.

## Exit gates
- Resume-after-edit, superseded worker, old denial replay, stale approval and uncertain-effect tests pass through actual runtime boundaries.
- Relevant simple workflows/processes run through shipped UI with recorded effect/read-back evidence.
- Saved-record compatibility and non-downgrade policy reviewed; mandatory specialized lanes run or explicitly block claimed coverage.

## Performance review
Required workload IDs: PERF-06, PERF-09, PERF-10, PERF-11. See [performance scenarios](../registers/performance_scenarios.json). Measurements remain unset until executed.

## Tests and downstream consumers
The [test catalogue](../docs/21-test-catalogue.md) and [mutation inventory](../registers/mutation_inventory.json) carry this phase ID. Discover actual current test assemblies, filters and counts before implementation. Updating a shared contract also invalidates affected UI/API/tool adapters, serialization snapshots, import/migration mappings and boundary tests even when their files were not directly edited.

## Safe stopping state
Named workflow/process paths are covered with explicit legacy restrictions; whole runtime safety is not inferred from a small scenario.

## Residual risks and integration notes
Largest integration blast radius; keep changes in reviewed sub-slices and re-run required frozen-checkpoint/platform gates.
