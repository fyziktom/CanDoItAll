# P02 · Projects end-to-end protected edit pilot

Status: **Proposed — not started or validated.**

## Goal
Close lost project edits, ambiguous save outcomes and the selected projection consistency gap across every enabled Projects caller.

## Dependencies and entry evidence
Dependencies: P01.

- P01 choices and proofs complete; deployable caller/migration perimeter approved.

## Included changes
- Add the reviewed content stamp to canonical schema and owner mapping; atomic parent/child/receipt behavior.
- Return a coherent editable snapshot and exact accepted stamp plus child identity mapping.
- Update ordinary UI hosts, API-only contract, agent tool request/binding and internal callers together; missing/stale preconditions reject.
- Implement draft-preserving conflicts, original operation reconciliation and chosen search projection protocol.
- Update transfer/import/maintenance token handling and drain unconverted writers; cover delete/recreate and original creation reservation/compensation.

## Explicit exclusions
- No full rich-text merge, shared cursors or per-keystroke autosave.
- No claim that old planning objectives are now detected by target CAS.
- No unconverted legacy endpoint that fills in a current token.

## Exit gates
- All enabled pilot write paths enforce original content/lifetime conditions; absent tokens cannot bypass.
- Real two-editor and agent-versus-human tests preserve data and drafts; duplicates/lost responses reconcile by owner result.
- Chosen projection, import and restore rules pass their actual crash/order tests.
- Targeted owner, contracts, UI and browser proofs plus required static gates are recorded on matching source.

The [test catalogue](../docs/21-test-catalogue.md) and [mutation inventory](../registers/mutation_inventory.json) carry this phase ID. Discover actual current test assemblies, filters and counts before implementation. Updating a shared contract also invalidates affected UI/API/tool adapters, serialization snapshots, import/migration mappings and boundary tests even when their files were not directly edited.

## Safe stopping state
Protected Projects edits and their declared projection/outcome guarantees can ship. Other owners and decision-basis freshness remain explicitly outside coverage.

## Residual risks and integration notes
Coarse project revision may cause benign conflicts. Deployment cannot restore old unsafe writers as a performance fallback.
