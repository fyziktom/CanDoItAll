# Architecture checkpoint questions

Every governed checkpoint must answer:

1. Which responsibility moved?
2. Which source type/project owned it before?
3. Which type/project owns it now?
4. Did the old owner shrink in responsibility, not only in line count?
5. Can the new owner be tested without the old runtime?
6. Which backend types were removed from the presentation contract?
7. Which adapter now maps them?
8. Were any new project references added?
9. Does CodeAnalytics prove the direction and absence of cycles?
10. Did any neutral component gain service location, dynamic backend switching, or a broad boolean matrix?
11. Did any named large type gain a new partial file?
12. Are Simple Chat types absent from production UI changes?
13. Are current Agent public entry points and user behavior preserved?
14. Which proof would fail if the extraction were only cosmetic?
15. What is the progression decision: pass, reopen, repair, or block?
