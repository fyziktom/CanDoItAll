# Installation

Unpack this directory under the repository bundle area, preferably:

`codex/bundles/CanDoItAll-Agent-Chat-UI-Reuse-Refactor-Phase-1`

Then run:

```text
python scripts/validate_all.py
```

The scripts require only the Python standard library.

Execution begins with `subbundles/SB01-baseline-architecture-and-ui-parity-contract/README.md`.
