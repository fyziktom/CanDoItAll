# Execution principles

- Preserve behavior first; reuse readiness is secondary to Agent parity.
- Move contracts and presentation before migrating consumers.
- Keep old public facades until all consumers are proven.
- Extract one responsibility family per subbundle.
- Do not refactor backend orchestration merely because the UI file is large.
- Do not create extra projects without a dependency reason.
- Do not put unrelated app UI into the Conversation project.
- Use typed mappings and slots rather than product-kind switches.
- Run affected proof after each coherent change, not after every edit.
- Use governed checkpoints to prevent cosmetic extraction.
- Stop at user handoff.
