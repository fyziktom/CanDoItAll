# Preparation limitations

The bundle was prepared from the live GitHub connector view of the `simple-chats` branch and the current SharedInfo repository.

Preparation did not:

- create a local repository checkout;
- run the CanDoItAll application;
- build production projects;
- execute bUnit, integration, or Playwright tests;
- create baseline screenshots.

Those are implementation-time SB01 obligations. The ZIP's own validators and checksums are preparation evidence only and are not evidence that the future refactor builds or preserves runtime behavior.
