# QA / Red-Team Prompt

Check every critical gate for:
- shallow-pass trap,
- adversarial negative proof,
- semantic positive proof,
- anti-stub audit,
- raw-note literal closure,
- changed-file hashes,
- command transcripts,
- no forbidden runtime/Core/driver/UI drift.

Reject status-only rows, non-empty diagnostic-only proof, fixture-only parsing, missing producer/consumer proof, and any runtime host behavior hidden behind read-only names.
