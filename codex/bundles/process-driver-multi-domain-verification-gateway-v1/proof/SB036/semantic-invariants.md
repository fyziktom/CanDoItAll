## SB036_INV_001
- Invariant ID: `SB036_INV_001`
- Source raw note: `Prepare broader phases toward stable Core and domain drivers`.
- Expected behavior: Gate L can close only when the ArtifactEvidence verifier is proven deterministic, read-only, supplied-descriptor-only, mutation-free, dependency-clean, and semantically adequate across positive descriptor verification, missing metadata diagnostics, supplied-envelope denial, wrong-family denial, projection order drift, missing lineage, trust/sensitivity mismatch, satisfaction inconsistency, audit facts, and no raw-text leakage.
- Disallowed shallow implementation: claiming closure because the package exists, because diagnostics are non-empty, or because one source scan omits a runtime-host token while skipping supplied-envelope binding, Core descriptor family binding, mutation denial, typed artifact diagnostics, audit facts, no-mutation response proof, and focused pass count.
- Failing-first test: `bundle://proof/SB036/transcripts/red-team-artifact-evidence-shallow-proof-rejection.txt` rejects closure without clean build, 6/6 focused ArtifactEvidence tests, positive supplied descriptor proof, missing metadata non-leak proof, envelope/family denial proof, package dependency proof, projection/lineage diagnostics, trust/sensitivity/satisfaction diagnostics, side-effect denial, no-mutation proof, source scan, and semantic artifact matrix.
- Passing test: `bundle://proof/SB036/transcripts/gate-l-proof-index.txt` verifies SB034/SB035 manifests, clean build, 6/6 focused ArtifactEvidence tests, Gate L source scan, red-team rejection, and this invariant contract.
- Changed source files: `repo://src/CanDoItAll.Processes.Drivers.ArtifactEvidence`; `repo://tests/CanDoItAll.Tests.Unit/ProcessDriverArtifactEvidenceAlphaTests.cs`; `repo://src/CanDoItAll.Processes.Drivers.Abstractions/Verification/ProcessDriverDiagnostic.cs`.
- Production assertions: ArtifactEvidence verifier accepts only supplied in-memory Core descriptor/snapshot objects, binds `CoreDescriptorPayload` to `CoreDescriptor` references with artifact projection/validation families, emits typed artifact diagnostics from supplied descriptors, returns immutable diagnostics/audit facts, and always reports `NoMutationPerformed: true`.
- Security assertions: artifact write and other side-effect operations are denied before descriptor analysis; source scan proves no runtime host, registry, selector, provider, DI, module, HTTP, process, file, directory, DbContext, workspace, storage, UI/media, or secret-like drift in Gate L targets.
- Adversarial negative case: a closure that checks only package existence, non-empty diagnostics, or one no-host scan is rejected with simulated verifier exit code 1.
- Downstream dependency check: SB037 and later observation aggregation phases may proceed only from proof that ArtifactEvidence remains supplied-descriptor-only and mutation-free; if ArtifactEvidence proof weakens, reopen SB034-SB036.
