# Original Request

The user wants the automatic process flow fixed in smaller parts by using a detailed CanDoItAll bundle with subbundles.

The first requested part is deterministic mock AI agents for process automation testing. These agents must not call real LLM providers. They should represent multiple cooperating roles in a simple Calculator app delivery flow, create artifacts, hand artifacts to one another through the existing process run, and cover the case where a developer creates work, QA rejects it, and the developer repairs it before QA approves.

The user also requires the mock-agent run to be controlled by settings so it is available only when tuning the process execution core.

The user explicitly asked to begin with a detailed map of the current process execution core and its connection to roles and agents.
