# Architecture Checkpoints

## Entry

Preparation inventory, scoped CodeAnalytics record and real project references establish owners. No new project or public contract is authorized. Existing complexity/module/type cycles are baseline findings, not cleanup scope.

## SB01 Foundation Gate

Review operation-lifetime/freshness proof, unchanged singleton public factory behavior, path security and payload durability. Direct tests must exercise any extracted internal fact helper without AgentFramework runtime. Downstream actual store commit smoke must pass before SB03.

## SB02 Foundation Gate

Review narrow projection versus materialization, preserved malformed-catalog/graph null behavior and supported token invalidation. A token-only shared availability check is rejected. Direct loader/materializer tests and snapshot-cache composition prove a real boundary.

## SB03 Foundation Gate

Prove immediate trusted-plan reuse is inaccessible from recovered journals or after lock reacquisition. Required metadata/index publication and post-journal cancellation semantics remain. Direct projection equality tests and all failure-boundary recovery tests pass.

## Every Gate

Run csharp-architecture-review-gate during future execution. Record before/after dependency direction and scoped CodeAnalytics findings; no new cycles or inward references. Audit no new partial files, nested behavior containers, service locator, broad public bypass flags or duplicated validation. Existing partial store may receive a small local change; no extraction-by-file-size is planned.

If behavior is extracted, show it left the old owner and direct tests instantiate the new cohesive top-level internal type. If local optimization is sufficient, record old-class shrink as N/A-local change and prove redundant work was removed rather than demanding a fabricated facade. Public contracts/composition stay unchanged.

Gate output: Pass/Fail/Blocked, exact evidence, downstream unlock and invalidation keys. Scope expansion reopens planning before code proceeds.
