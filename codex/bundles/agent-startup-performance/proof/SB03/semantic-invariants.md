# SB03 Semantic Invariants

Architecture decision: reuse only the existing typed payload comparison result after a fresh conflict read, with explicit trusted call-site origin. No snapshot authority is inferred from a workspace lock; noncooperating edits before validation still fail. A private generic helper removes four copies of payload persistence logic while preserving the existing execution-slice/chat ownership boundary. See design-review.md and independent-implementation-review.md.

Linux symlink/private-mode execution is inherited from SB01; this new work does not claim those cases ran on Windows.
