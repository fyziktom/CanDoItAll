# Independent QA Prompt

Determine whether this bundle is prepared for later execution, or whether an executed phase can close. During preparation perform read-only source/document review only: no tests, builds, browser actions, provider requests or deployments.

Check exact raw scope1-3 and excluded batching; runtime source ownership; case-freshness/security; local/shared validated-availability parity including unchanged-token malformed data; immediate-vs-recovery trust; mandatory timestamp/index metadata; test filters/nonzero discovery; Linux/Windows scenario capability; isolated database/fault safety; real UI conversations/tools on both named hosts; accurate timing marker semantics; no fabricated completion.

During future closure inspect underlying governed artifacts, not just status tables. Check retained per-stage logs, actual tool results grounded in assets, approval behavior, errors, continuation/reload and host rollback. Report Pass/Fail/Blocked, concrete defects, needed repairs and downstream invalidation. No unrelated refactoring or policy changes.
