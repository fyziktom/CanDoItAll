# Hard Constraints

- No Process Core.
- No production driver API.
- No MAF/Tooling product dependency broadening.
- No UI, Razor, CSS, JS, TS changes.
- No small/medium/mobile/phone/tablet proof.
- Existing wrapper methods must remain unless the subbundle explicitly proves equivalent callers and test parity.
- Route helpers must be decision-only unless explicitly named as side-effect coordinators.
- Claim/heartbeat helpers must not hide lost-claim exceptions.
