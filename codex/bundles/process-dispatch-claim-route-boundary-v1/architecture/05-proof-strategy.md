# Proof Strategy

Every production movement subbundle must include:

- source scan,
- focused unit tests for helper behavior,
- focused integration tests for dispatch/concurrency behavior,
- line-count scan,
- no-core/no-driver scan,
- MAF/Tooling dependency scan,
- no prohibited viewport proof scan.

Critical gates:

- Gate A after inventories and architecture guards.
- Gate B after execution selection helper migration.
- Gate C after route/claim movement.
- Gate D after finalizer context factory and driver-readiness docs.
- Final red-team before closure.
