# Proof Directory

Each critical subbundle must complete its own proof directory before closure.

Required per subbundle:

- `manifest.md`
- `semantic-invariants.md`
- `transcripts/` with failing-first and passing command transcripts
- source assertion artifacts
- anti-stub audit output
- changed-file hash manifest
- red-team or verifier artifact for SB09 final closure

Prepared placeholders are intentionally not closure proof. They define the evidence contract that implementation must fill.
