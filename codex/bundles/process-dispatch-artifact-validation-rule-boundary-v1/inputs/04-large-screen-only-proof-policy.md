# Large Screen Only Proof Policy

Default browser validation for this bundle: `N/A - service/runtime refactor only`.

If Codex unexpectedly changes UI-visible files or must run UI proof, use only large desktop/PC viewport proof.

Forbidden proof categories:

- mobile
- small-screen
- medium-screen
- phone
- tablet
- Android
- iPhone
- responsive optimization proof

The final gate must include a proof-path scan that rejects these terms under the bundle proof directory.
