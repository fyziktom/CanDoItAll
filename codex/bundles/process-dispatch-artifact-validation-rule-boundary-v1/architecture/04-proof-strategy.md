# Proof Strategy

Every extraction must include:

- failing-first or adversarial source scan where feasible;
- direct unit/integration tests for new helper behavior;
- targeted artifact validation regression slice;
- full solution build at major gates;
- source scan proving no Process Core or driver pack project;
- source scan proving no MAF/Tooling product dependency regression;
- proof-path scan proving no prohibited viewport artifacts.

For UI proof: default N/A. If UI proof unexpectedly becomes necessary, large desktop/PC only.
