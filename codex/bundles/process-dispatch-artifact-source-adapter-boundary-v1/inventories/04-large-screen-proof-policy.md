# Large Screen Only Proof Policy

This bundle is runtime/service refactoring. Browser validation should be `N/A` for every subbundle unless a rendered UI route is unexpectedly modified.

If browser proof becomes unavoidable:

- Use only a PC/large desktop viewport.
- Do not create small, medium, mobile, phone, tablet, Android, or iPhone screenshots.
- Do not optimize for responsive/mobile layouts.
- Record why browser proof was unexpectedly needed.

Final closure must scan proof paths and reject prohibited viewport artifacts.
