# Runtime definition of done

Runtime portability is done only when Final Gate R4 is GO and:

- all runtime P0 requirements are `Solved`;
- Core C4 remains green;
- one process execution/lifecycle foundation is authoritative;
- Workbench runtime nodes execute directly on Windows/Linux/macOS and terminal/elevation are truthful optional capabilities;
- Manager never kills a foreign process and recovers owned processes safely on all three OSes;
- local stdio MCP and a governed external tool pass actual-host E2E;
- Docker/FileTools/native dependencies have exact compatibility evidence or are disabled truthfully;
- process strategies consume host capabilities without moving domain semantics into MAF/Infrastructure;
- failure injection and secret redaction pass;
- active CI and the final support/limitation matrix are complete.
