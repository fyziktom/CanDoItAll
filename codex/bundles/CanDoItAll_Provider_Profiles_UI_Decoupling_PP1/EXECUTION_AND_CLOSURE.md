Use disposable task-owned PostgreSQL 18 fixtures and synthetic credentials/providers on loopback. Ordinary port 5032 and existing profiles are not fixtures. Check ownership before stopping/deleting any task resource. No real email/payment/deployment, source publication, credential issuance, arbitrary script execution or unbounded model action. Before approving an agent tool proposal, verify the exact expected project, node, path, input and overwrite policy, not just its tool name. Capture native result IDs and bytes. Redact shareable artifacts, never weaken secret scanners; retain raw originals privately with hashes. Do not commit transcript/provider payloads, credential-valued discovery output or screenshots of live secrets.

## Repairs versus new architecture

Fix small reproduced lifetime, event, projection, validation or affected assertion defects with regression tests. If a change requires a new durable protocol, migration, authority expansion or cross-owner redesign, map concrete cause, original/current behavior, exact effects, scope and safe containment for a later bundle. Stop unsafe dependent mutations; continue independent safe work. Documented is not repaired.
