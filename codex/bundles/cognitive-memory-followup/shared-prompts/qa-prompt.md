# QA Prompt For Codex

Act as an adversarial reviewer. Your goal is to prove whether the subbundle can still pass through a shallow shortcut.

Check:

- Are proof artifacts present and referenced by path?
- Did the negative tests fail before implementation?
- Do positive tests assert domain behavior, not only non-empty output?
- Does the source code implement the behavior in production services?
- Are direct professor anchors prevented from acting as stable knowledge before assimilation?
- Does every synthesized recall statement have precise lineage?
- Are service boundaries small enough to be reviewable?
- Did any test rely on exact fixture strings that a shallow implementation could satisfy?

If any check fails, mark the subbundle `In progress` or `Blocked` and create a concrete repair step.
