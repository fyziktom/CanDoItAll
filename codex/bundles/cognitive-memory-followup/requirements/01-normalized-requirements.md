# Normalized Requirements

## Process Requirements

- R-01: The bundle workflow skill must require artifact-backed proof manifests before a critical subbundle can close.
- R-02: The completed-stage validator must reject prose-only semantic evidence even if all labels are present.
- R-03: Critical subbundles must have failing-first negative tests and semantic positive tests recorded as artifacts.
- R-04: A red-team verifier pass must run after feature subbundles and before final closure.

## Cognitive Memory Requirements

- R-05: Clustering must form candidate pairs from composite semantic evidence, not only exact shared strong keys.
- R-06: Clustering must detect and split or review bridge/chain clusters with low endpoint cohesion.
- R-07: Clustering must preserve contradiction/review clusters even when a contradiction relation is the primary signal.
- R-08: Dreaming must integrate complementary claims into aggregate statements and avoid representative-copy output unless the mode explicitly asks for quote preservation.
- R-09: Dream validation must use statement-to-source entailment/coverage checks stronger than token overlap.
- R-10: Dream modes must produce structurally different outputs for procedure mining, failure learning, coverage refresh, and project nightly consolidation.
- R-11: Curator/professor mode must capture natural teaching conversation without requiring explicit remember/correct keywords.
- R-12: Professor guidance must be stored as structured temporary anchors with claims, targets, scope, misconceptions, and confidence.
- R-13: Assimilation must require independent non-descendant support, repeated successful use or dream integration, and explicit mastery criteria.
- R-14: Fading must demote/retire direct professor quote memory after mastery while retaining reference-on-demand lineage.
- R-15: Recall synthesis must produce concise task-facing briefs, separate conflicts/caveats, and avoid internal scores/references by default.
- R-16: Reference resolver must return precise statement-to-claim-to-source lineage for requested statements only.
- R-17: Large services must be refactored into testable domain collaborators with versioned algorithm configuration.

## Scope Guard

- R-18: Do not include economic memory governance models in this bundle.
