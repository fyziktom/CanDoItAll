# Structured Input

## Main Questions To Answer In Code

1. Can the current bundle workflow prevent shallow completion?
2. Does clustering form semantically coherent clusters from multiple keys and split weak bridge components?
3. Does dreaming produce real aggregate knowledge rather than representative source copies?
4. Does dream validation reject unsupported or merely token-overlapping claims?
5. Does professor/curator mode support comfortable natural learning with a human source of truth?
6. Does professor guidance become internalized only after independent support and repeated application?
7. Does recall produce a concise task-facing brief with exact references available on demand?
8. Are tests adversarial enough to fail the current shallow implementation before feature changes?

## Required Execution Style

- Start with failing-first tests and artifact-backed proof gates.
- Use deterministic tests for all acceptance criteria.
- Do not mark a subbundle complete from prose-only evidence.
- Do not count non-empty output, status transitions, or table rows as semantic proof.
- Preserve exact source lineage for every synthesized statement.
