# Original Request

The user asked for three follow-up improvements after the initial subprocess work:

- Add another tab in the process detail area after `Exchange`. The tab must be a standard chat with the process manager agent responsible for the selected process.
- The manager chat must include a button that opens a modal for selecting the specific process run the user wants to discuss with the manager.
- Add a subprocess for implementation of functions/features and use it in the main development process as one of the steps.
- Test the updated process behavior on a random real-world small-app development topic similar to existing project examples.
- Observe whether agents can deliver by themselves. Do not manually write the app for them during that validation.
- If agents block or fail, analyze what happened, what the manager should do next, and improve generic dispatcher behavior only when the improvement is truly generic.
