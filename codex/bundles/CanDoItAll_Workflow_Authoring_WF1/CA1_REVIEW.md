Reviewed main: `ccca2fd3a7c4239d2869e8143617fd9ab04c3723`, after seven commits from PP3.
The change includes the historical CA1 package and distinct implementation/test/documentation work.
This review read source and the tracked implementation report. It did not run .NET, Docker,

## Preserve

The actual capability wizard and details share a new rendering leaf, typed configuration fields,
raw repair, upload and operation-aware form. Native setup and catalog operations remain in the module.
The current session snapshots requests before awaits, adopts accepted identity/fingerprint and keeps
later edits. Setup diagnostics are separate from Save and A2 proof publication. Sources: S02–S07, S29.

The team UI is in the existing AgentFramework.UI family. The additive metadata operation captures
name/description/icon before waiting and preserves existing membership at the coordinated write;
legacy full-team upsert remains unchanged. Member requests freeze the supplied ID array. S08–S09.

The bounded MCP checkpoint repair supports only installed MCP ContentBlock/ResourceContents with the
SDK serializer and package check. Unknown raw objects, foreign types and incompatible packages remain
explicit recovery cases. It does not weaken approval or replay external effects. S10–S11. The report's
native journal/restart evidence is valuable, but the review did not repeat those tests.

The Workflow OpenAPI follow-up is reported fixed in the original 23-case family. Do not repeat the
old documentation assignment or remove public fields. Retain the native default-model projections.
