# Roadmap after CA1

This is the selected-family roadmap, not a claim that every Razor file in AgentFramework must move.
A retained host can legitimately own route, profile, authorization, trusted composition or effects.
Effort is relative architectural complexity, not hours or a promised run duration.

| Family | State / next action | Relative effort |
|---|---|---|
| Workspace and Projects | Completed selected renderers; preserve owners and targeted regression coverage | No new blanket extraction |
| Agent Editor A2, Providers PP1/PP2/PP3, capability/team CA1 | Completed selected families; small CA1-R1 precedes WF1 | Bounded follow-up |
| Workflow authoring WF1 | Full canvas, inspectors, component binding and current page-owned dialogs in this package | 4–5/5; one larger staged assignment |
| Residual Agent chat/usage/Voice/provider operation renderers | Current caller census, then bounded real remaining surfaces; do not create missing screens from API names | 2–3/5 pending census |
| Workbench | Smaller calendar/read/task/assignment surfaces first; Structure/canvas/file/runtime boundaries later | 5/5 whole family |
| Processes | Catalog/definition, admission/launch, live monitoring and recovery; last major family | 5/5 whole family |
| Web/shared composition audit | Reusable remaining renderers versus legitimate composition only | 2–3/5 pending census |

The existing Workflows.UI shell/catalog/history/templates/overview/analytics already exists; WF1 must
not count those as new work or inflate their dependencies. At final census explicitly name any still
unextracted real Workflow renderer and its caller. If it belongs to the selected family, finish it;
if it is a distinct native operation family, explain the boundary without claiming it complete.

Update current `docs/architecture/modules.md` and per-project READMEs, not the sealed shared audit.
Do not begin Workbench or Processes automatically after WF1.
