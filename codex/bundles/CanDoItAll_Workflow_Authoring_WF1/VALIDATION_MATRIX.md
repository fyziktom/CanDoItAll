## Existing entry points to inspect and retain

`tests/Components/CanDoItAll.Tests.Components/WorkflowsPageTests.cs` includes native canvas preview,
curator and starter paths. Retain `WorkflowSurfaceTests`/`WorkflowOwnershipTests` and current executor,
Prompt Gallery, scheduler and structure-delivery families found through the entry caller census.
The latter names are starting points, not an assertion that this review read each entire suite.

Build changed native/UI projects directly. A lightweight renderer test project may be created if needed;
register it in the proper test solutions and all applicable current CI selections, never the product
solution as a test project. Do not miss a host scope when editing a repeated component selector list.

A test that exits behind an environment gate is NOT_RUN/BLOCKED, not proof of its body. A warm UI row,
heading or old page can satisfy an assertion before a replacement query is accepted. Await the exact
new owner/row/state and inspect deterministic counters. Avoid unlimited sleeps or test retries.

G30 is accounting of the deliberate final regression checkpoint. A PASS accounting review can retain a
mixed original test and explicit focused dispositions; it does not permit calling that test PASS.
All other functional topics need actual successful relevant evidence. No scanner, source grep or
package-validator result substitutes for a native owner or browser behavior test.
