## APIs To Prefer For Follow-Up Analysis

Use these before reading database rows:

- Process run detail with include flags.
- Step-scoped artifact routes when reviewing a specific failed or questionable step.
- Agent execution run detail, tool receipts, artifacts, checkpoints, logs, and metrics.
- Workflow run detail, events, artifacts, checkpoints, pending requests, and executor catalog.
- Agent provider/capability editor routes if provider or capability configuration needs exact DTO shape.
- Process template detail/envelope routes when checking template sidecars, operation contracts, subprocess mappings, and compatibility notes.

Do not patch database rows or copied JSON directly for analysis.
