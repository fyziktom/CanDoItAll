# Prompt / fit-gap summary

**Key:** `prompt-fit-gap-summary`  
**Scope:** local  
**Process:** customer-onboarding  
**Audience role key:** `solution-consultant`  
**Phase:** solution-design

## Summary
Prompt scaffold for fit-gap summaries that convert workshop input into actionable design choices.

## Required inputs
- customer process notes
- product capability limits
- open questions

## Output schema
- supported configuration
- gaps
- workarounds
- required product decisions
- customer actions

## Refusal conditions
- Refuse to label a gap as solved if the workaround is unsupported or still hypothetical.
