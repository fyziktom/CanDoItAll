# Release go-live checklist

**Key:** `release-go-live-checklist`  
**Scope:** shared  
**Process:** shared  
**Owner role key:** `release-approver`  
**Phase:** release

## Summary
Final go-live discipline checklist for deployment readiness and operational ownership.

## Entry criteria
A release is approaching a production decision point.

## Exit criteria
Decision-makers have explicit evidence on quality, security, rollback, monitoring, support, and communication readiness.

## Checks
- Release scope and version identity are explicit.
- Open conditions and residual risks are documented.
- Rollback trigger and rollback owner are defined.
- Monitoring and first-hour watch coverage are scheduled.
- Support, customer, or stakeholder communication plans are ready if needed.
- A named release decision owner has reviewed the evidence set.

## Evidence expectations
- Release readiness report.
- Rollback plan.
- Watch roster or equivalent operational note.
