# Incident triage explicit

**Key:** `validation-incident-triage-explicit`  
**Scope:** shared  
**Process:** shared  
**Owner role key:** `triage-lead`  
**Gate:** Incident triage  
**Failure severity:** Error

## Summary
Prevents triage from moving forward with unstated severity, unnamed responders, or vague impact framing.

## Pass criteria
Severity, responders, impact hypothesis, and first actions are documented explicitly in the triage note.

## Fail criteria
Severity, responders, impact, or first actions are implied only through chat or memory.

## Escalation rule
Pause progression until the triage note is explicit and replayable.
