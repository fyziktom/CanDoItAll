# QA Prompt

Validate that the shipped behavior supports generic Blazor WASM PWA application delivery.

Check:

- No reusable process template, process API skill, or reusable instruction contains a fixed app topic.
- Live-run profile data has no completed transitions or artifacts.
- Seeded regression data cannot be mistaken for live agent-executed proof.
- Product mutation is limited to implementation and repair steps.
- Browser proof requires current route, screenshot, console, DOM/state, visible behavior assertions, and cleanup where applicable.
- Project-structure writeback records controlled external-action receipts or blocks explicitly.
