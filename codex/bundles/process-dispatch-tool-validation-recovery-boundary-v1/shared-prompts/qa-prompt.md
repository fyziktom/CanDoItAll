# QA Prompt

Review the completed bundle as a skeptical senior C# architect.

Check:

- Did any Process Core or driver-pack code appear?
- Did any helper gain EF/storage/file-system/MAF/Tooling/product-module dependencies unintentionally?
- Did required-tool behavior change?
- Did critical failure handling change?
- Did completion status/reason behavior change?
- Did recovery/retry behavior change?
- Did the implementation preserve process mock and carried proof special cases?
- Did any small/medium/mobile proof artifacts appear?
- Are line counts and source scans recorded?
- Does the final cutline tell the next implementation agent exactly what to do next?
