of missing decoupling; routed/native effect composition can remain in the product module.

Do not start the next row automatically after PP2. Update maintained docs with the real renderer,
host, child, asset and dependency census. History is not complete merely because the parent has
a slot. Conversely native provider identity/credential/dispatch services are not 'leftover UI'
that must be moved into the leaf. Keep shared v3 historical module map sealed; current roadmap
belongs in maintained repository docs and this report.
