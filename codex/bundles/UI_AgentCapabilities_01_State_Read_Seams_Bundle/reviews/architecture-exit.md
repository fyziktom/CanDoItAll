# C01/C02 architecture review

PASS for the bounded state/read seam. The existing panel is the sole effect host; the new surface renders immutable presentation snapshots and emits closed typed intents. The session owns accepted selection, retained pending target, editor, catalog, Loading/Ready/Failed state and each cancellable read generation. The page remains owner of requested identity. Callback and parameter acknowledgements only suppress echoes; they never override session state. A missing target remains missing through Retry, as proved in browser and Unit tests.

The surface has no feature injections, persistence, dialogs, notifications, transport DTO, mutable editor or service calls. It retains only filters, expanded nodes, the typed local preview draft and pure presentation mapping. One cohesive read port has a real workspace adapter and direct fake tests. All six existing effects stay in the host; no interface per event, service bag, controller hierarchy, new product project or cross-project source move was introduced.

The current-generation predicate fences late read success and failure, callback continuations and effect completions. Owned read sources are cancelled/disposed on supersession and disposal. Busy fields are generation-bound, including migration to the generation created by the operation's own refresh. Current read failure renders a controlled retry state and clears the prior editor. Assignment still edits the mutable model before Save; mutation outcome, rollback, cancellation and owned nested dialogs are explicitly not hardened here.
