# Proof Strategy

## Unit Proof

- Pure matcher tests.
- Lineage/external-reference key tests.
- Projection candidate planner tests.
- Selected validation rule tests.

## Integration Proof

- Existing process dispatch artifact-lineage smoke.
- Required artifact expectation satisfaction/unsatisfaction tests.
- Receipt metadata and required-tool family tests.
- Process-filtered integration test slice.

## Source Scans

- No Process Core/driver-pack project.
- No MAF product dependency.
- No mobile/small/medium viewport proof artifacts.
- No broad UI file changes.
- Dispatcher partial line-count review before and after.

## Refactor Gates

- Gate A after design and guardrails.
- Gate B after first projection migration.
- Gate C after validation rule foundation.
