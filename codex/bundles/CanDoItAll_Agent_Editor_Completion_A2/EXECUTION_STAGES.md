# One larger continuation, staged for useful checkpoints

| Stage | Deliverable | Before moving on |
|---|---|---|
| E0 | Current source/sibling provenance, archive/product diff, caller and graph census | Preserve historical handoffs; determine real build/test prerequisites |
| S0 | Failing-first A2-R1 verification reconciliation repair | Native proof/version and preserved unsaved draft; regression controls pass |
| A2a | Project access, Secrets and Process access renderers | Actual same-form binding, lazy/failure states, missing references and native scopes preserved |
| A2b | Memory/bindings, Workspace tools/root rendering and real Storage picker composition | No driver/registry dependency in leaf; real path/lifetime/selection and subform controls |
| A2c | Capabilities section, create/assign/Verify follow-up, small confirmation renderers | Separate effects, no accidental hidden Save, proof review and independent overlays |
| V1 | Full ten-section sandbox, production adapters and published assets | Real widgets, two editors, deterministic scenario state; no opaque forwarding sections |
| V2 | Final owning tests and application consumer campaign | Frozen input/proof relation, negative scopes, real file bytes, broader-test impact decision |
| C | Source-bound evidence, renderer census, roadmap, signed scoped commits as appropriate | Honest status for implementation, native proof, blockers and exact dependencies |

The order within A2a/b/c may change for a demonstrated dependency reason. Do not require approval
between every stage, and do not stop after the first newly extracted tab. Keep stage changes
reviewable and avoid mixing unrelated provider administration into the same commit.

A small confirmed regression is fixed in the same task. A complex authority/schema/durable-protocol
problem gets a preserved reproduction and a precise impact map, not speculative redesign. Complete
other safe stages where possible and mark the blocked acceptance group. Mapping is not repair.
No report should claim the ten-section editor complete if a whole selected section is still hidden
inside a production-only deferred fragment or the sandbox substitutes fake markup for it.
