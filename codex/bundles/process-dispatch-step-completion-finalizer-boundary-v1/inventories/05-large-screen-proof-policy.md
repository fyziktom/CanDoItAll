# Large Screen Proof Policy

This is runtime/service refactoring.

- Browser validation default: N/A.
- Do not run mobile/small/medium/tablet/phone/responsive proof.
- Do not create proof artifact paths containing mobile, small, medium, phone, tablet, Android, iPhone, responsive.
- If UI files unexpectedly change, stop and record a scope exception. Only large desktop/PC proof may be planned after explicit justification.
