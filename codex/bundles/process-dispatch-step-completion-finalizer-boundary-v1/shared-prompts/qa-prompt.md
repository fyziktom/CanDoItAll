# QA Prompt

Review the completed subbundle as a skeptical senior architect.

Check:

- Did the subbundle stay in scope?
- Did it avoid Process Core and driver-pack production APIs?
- Did it preserve finalizer behavior?
- Are source references exact?
- Are tests behavioral, not compile-only?
- Are browser validation entries correctly marked N/A?
- Are no prohibited viewport proof artifacts present?
- Did line counts and helper responsibilities improve without hiding side effects?
