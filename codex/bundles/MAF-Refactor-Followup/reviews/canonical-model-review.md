# Canonical model review

Review these sources of truth separately:

- product/project state
- UI observation
- conversation affinity
- turn context reference
- execution authority/governance snapshot
- execution run
- tool proposal and approval decision
- runtime-state envelope
- process outcome/artifacts/gates
- workflow run and lightweight LLM response

For each, record owner, identity, mutator, persistence, projections, and whether another layer can overwrite the same truth. Block if UI state, MAF session state, tool traces, or projections can override product authority or durable execution/process truth.
