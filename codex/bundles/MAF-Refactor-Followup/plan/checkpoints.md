# Architecture checkpoints

## CP1 — Authority integrity (`SB03`)

Block unless UI hints cannot grant, source providers are explicit, and one governance snapshot controls scope/composition/invocation/continuation.

## CP2 — Scope and lifetime (`SB07`)

Block unless every run uses one complete workspace identity and one owned bundle/process host across tools, recovery, scripts, handoff, and profile switch.

## CP3 — State and continuation (`SB10`)

Block unless envelope/native payload semantics, v0/v1/v2 migrations, effective history, fingerprints, and exact approval continuation pass restart fixtures.

## CP4 — Governance and approval (`SB13`)

Block unless per-proposal decisions are exposed and MAF uses an injected provider-neutral policy with process restrictions outside MAF.

## CP5 — Final release (`SB17`)

Block on any authority/scope/state/approval/process-boundary regression, newly accepted test failure, unresolved lease-token contract conflict, missing architecture proof, or absent durable build/test transcript.
