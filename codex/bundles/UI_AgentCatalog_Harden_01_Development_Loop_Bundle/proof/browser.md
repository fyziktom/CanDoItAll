# Real browser and asset acceptance

Both Parity and Fast completed the direct local browser acceptance at 1600x1000 with the real catalog/card/tree/tooltip/avatar components. Original ledgers are under runs, and selected original screenshots are under browser/parity and browser/fast. Normal screenshots for both modes plus Fast tooltip, loading, empty, card states and avatar fallback were visually inspected. The cards/tree remain readable, their scroll owners are intact, and the primary New action remains inside the viewport.

Public search filters 40 cards to 12 fixture cards and resets to 40. Team/all selection, card selection and New emit the actual typed specimen intents. Hovering the real reset button opens the tooltip. Loading utilities produce margin-top 4px, weight 600 and size 18px; empty state is styled. Favorite state waits for aria-pressed=true. Avatar fallback uses the actual explicit initials contract. All 40 normal avatar images load, Material Symbols fonts load, toolbar is flex with 12px row gap, title is 20px/600, and card/tree scroll owners use overflow:auto.

Parity serves exactly the production root CSS SHA recorded in final-assets.json, with BaseLib compiled theme/fonts/icons and component isolation. Fast serves exactly its separate local root CSS SHA and has no /css/output fallback. BaseLib's own compiled output remains a legitimate shared asset. Active compiled mode is verified both on html[data-asset-mode] and the readiness probe, together with owner ID, PID and watch iteration. Fast's reduced theme omits unrelated application shell/admin/reconnect styles and does not claim byte-for-byte Parity rendering.

Direct build checks prove Fast succeeds while production CSS is absent and fails clearly when its own CSS is absent. Missing assets are not hidden by fallback. Final Fast CSS regeneration after the README encoding correction yields the same frozen bytes. The 27 warm trials include actual CSS edit/undo browser predicates in both modes and fullapp; every Fast trial and final shutdown preserve the production CSS hash.
