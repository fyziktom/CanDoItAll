# QA Prompt

Review the completed subbundle against the bundle contract, not against intent. Verify prerequisites, exact source references, acceptance checklist, proof paths, browser analytics rows, and progression gate status.

Critical gates must reject shallow proof. Require a semantic positive case, an adversarial negative case, source assertions, anti-stub scan, no-core/no-driver scan, no prohibited viewport proof scan, and an artifact-backed manifest whose cited paths exist.

Browser validation should remain N/A because this is runtime/service refactoring. If UI files changed, stop and require explicit large desktop proof before closure.
