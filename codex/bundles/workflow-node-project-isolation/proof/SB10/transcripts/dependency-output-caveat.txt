# SB10 Dependency Output Caveat

An existing CanDoItAll.Web process was running during SB10 and locked default Web build outputs. The implementation did not stop that process. Focused test/build proof used isolated output paths instead:
- Unit tests: C:\repositories\CanDoItAll\artifacts\sb10-unit-output\
- Component compile: C:\repositories\CanDoItAll\artifacts\sb10-components-output\
- Component compile used -m:1 to avoid shared output copy contention.
