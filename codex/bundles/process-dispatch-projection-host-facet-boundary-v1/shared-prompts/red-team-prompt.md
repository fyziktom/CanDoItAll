# Red-team prompt

Try to prove that the refactor is shallow or unsafe. Look for:

- helper files that exist but are unused;
- broad host dependency still used by source coordinators;
- projection source-family order drift;
- duplicate candidate mutation logic;
- hidden file/EF/storage side effects behind pure names;
- Process Core or driver API drift;
- UI or prohibited viewport proof drift;
- missing manifests or non-portable proof paths.
