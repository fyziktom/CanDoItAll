# Proof Strategy

Every critical phase must produce:

- source movement proof;
- focused subprocess route/projection tests;
- line-count review;
- no-core/no-driver scans;
- no UI/prohibited viewport scans;
- anti-stub audit;
- full build or module build at required gates.

Required focused behaviors:

- subprocess start transition fields;
- child run failure/block/observe/completed mapping;
- capability-gap block reason;
- parent artifact projection key and lineage;
- projection gap journal dedupe;
- parent-scoped markdown path safety;
- finalizer context fields for subprocess parent;
- no lost dispatch claim checks.
