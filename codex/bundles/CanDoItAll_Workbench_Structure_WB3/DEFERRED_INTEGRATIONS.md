# Preserve these integrations without falsely claiming their extraction

The native route still composes multiple product owners. WB3 separates the main
structural authoring surface, not every specialized action in Workbench.

| Integration | Required now | Deferred renderer work |
|---|---|---|
| WB1 Calendar/Gantt/task editors | Keep real tabs/actions, original task sessions and pricing behavior | None; do not redo completed WB1 |
| WB2 Summary/Selection/Index/Signals/Health | Mount the actual leaves and preserve exact origin-bound dispatch | None; do not rebuild report or support UI |
| Projects modal from hierarchy | Open original Projects UI, preserve returned identity and partial creation outcomes | Projects is already extracted |
| Party/meeting/assignee pane | Keep current native form usable via an explicit native sibling/slot | Full specialized affiliation/directory/assignment presentation |
| Secret reference/create | Keep real protected picker/SecretField and original secret owner | Dedicated secret form extraction, not plaintext in Structure DTOs |
| Text/media/transcript/image authoring | Correctly dispatch dedicated native editor and preserve original output | Full file/media authoring and generation UI |
| File browser, preview, Mermaid | Correct original targets and content grants; real native smoke tests | Workbench file-specific renderers and content lifetimes |
| Workflow/Process add/start/recovery | Keep exact definition/version, task/project input and original admission | Specialized integration dialogs; Processes product surfaces remain last |
| Runtime/terminal/web preview | Keep explicit native launcher/stop/approval and supported platform rules | Full runtime presentation extraction |

Use named, cohesive active slots or an equally explicit native composition. Do not
pass a huge service bag or wrap the entire old page inside the leaf. Do not register
production services in the sandbox so that these slots appear implemented.

The sandbox must use actual in-scope renderers. It may compose the already-light
WB1/WB2 leaves, with clearly synthetic data, to demonstrate shared layout and focus.
A deferred native effect gets a visible controlled host action and is separately
covered in production; it is not a fake positive owner test.

No menu action may disappear merely because its specialized renderer is deferred.
Do not introduce generic fallbacks that bypass owner editors, decode secret values,
open unsigned file routes or launch a process from a template preview.
