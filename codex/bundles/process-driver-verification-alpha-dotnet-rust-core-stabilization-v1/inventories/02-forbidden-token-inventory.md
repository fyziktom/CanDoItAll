# Forbidden Token Inventory

The following tokens must fail if they appear in the new alpha implementation package unless explicitly listed as harmless in tests/docs only:

- Registry
- Selector
- RuntimeHost
- ServiceCollection
- AddProcessDriver
- ExecuteCommand
- Process.Start
- Directory.
- File.
- Workspace
- Storage
- Graph
- Office365
- Gmail
- TransitionStep
- DispatchClaim
- Finalize
- RetryScheduler
- DbContext
- AppDbContext
- AgentFramework
