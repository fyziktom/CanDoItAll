# Package validation

This package contains an English implementation brief, its source register, a Czech
review, an unchanged 22-file shared v3 foundation, and consistency-checking helpers.
It contains no product patch, database, test TRX/media, dependency binaries or fonts.

The generated validation record lists actual integrity and helper-test results.
These prove handoff consistency only, not C# correctness or authentic product execution.
All 29 product groups start NOT_RUN. The completion check must reject that template.

Manifest entries cover every delivered file except the root manifest itself.
Local Markdown links are checked for existence and containment; remote URLs and
heading anchors are not fetched by the validator. The sources record exact reviewed
refs/ranges; it is not a claim to have audited every source file in either repository.
