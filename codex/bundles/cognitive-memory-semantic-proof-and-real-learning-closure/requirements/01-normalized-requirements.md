# Normalized Requirements

- R01: Completed bundle proof must be portable. No manifest, transcript, or active-skill proof may require absolute Windows, POSIX, WSL, user-profile, or local checkout paths.
- R02: Execution proof must include claim-to-code semantic verification. Capability labels must map to concrete source patterns, tests, and negative fixtures.
- R03: Add failing-first tests for every remaining gap before production changes.
- R04: Professor/curator capture must support natural Czech and English teaching, diacritic-insensitive matching, Q&A, corrections, examples, and counterexamples while preserving original utterance text.
- R05: Accepted-use evidence must be emitted through a real outcome/feedback workflow, not only through direct service tests.
- R06: Approximate clustering must either truly use embeddings/rankers or be honestly named and tested as lexical fallback. Paraphrases without shared exact/alias tokens must be discoverable when embedding providers are available.
- R07: Dream synthesis must produce domain-useful internalized claims, not diagnostic text about source claims or source maps.
- R08: Dream aggregate provenance must be claim-specific by loading and using claim-evidence links or equivalent exact claim support.
- R09: Recall synthesis must produce requester-facing briefs and maintain statement-level lineage that can resolve exact supporting claims and sources on demand.
- R10: Refactor large services into stable boundaries and centralize configuration/options so future changes are maintainable.
- R11: Final validation must include red-team end-to-end proof across Czech professor teaching, dream consolidation, semantic clustering, accepted-use integration, assimilation/fading, recall synthesis, and reference resolution.
