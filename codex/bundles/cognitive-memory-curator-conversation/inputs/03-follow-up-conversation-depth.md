# Follow-Up: Conversation Depth Modes

The curator conversation must support a setting for the type of conversation response: short, medium, or longer. This setting controls how concise or detailed curator replies should be.

The same setting must also control how much input knowledge is pulled into aggregation/capture. Short conversations should use less recall and aggregation context. Medium should keep the balanced default. Long conversations should use more recall and aggregation context so richer corrections and teaching input can be connected with more memory evidence.

During this follow-up, review the `cognitive-memory-curator-conversation` bundle and repair or implement any missing requirements.
