# Retained isolated browser fixture

Evidence source only; this is not a production or solution project. It hosts the real Web application with the repository TestEnvironment and isolated database/file stores, and adds test-only lost-response decorators. It never uses the user's live database or invokes an arbitrary endpoint or chat prompt.

To reproduce, copy the three original fixture files into `.mcp-state/capa02g-browser-fixture/` at repository root. Their relative project references intentionally resolve there. Build with `dotnet build .mcp-state/capa02g-browser-fixture/CapabilitiesBrowser.csproj -c Release /m:1`, then launch the built CapabilitiesBrowser DLL with the repository root as its sole argument. Dedicated ports 5273 and 17301 must be free. Run the retained browser-acceptance.cjs with CAPA_PLAYWRIGHT pointing to the installed Playwright module and an output directory. The normal final path minimizes the inspected chat before acknowledgement.

Stop only this owned fixture through POST /fixture/stop on its isolated loopback control port. Runtime credentials are generated by TestEnvironment and are not retained in this bundle. Do not add this fixture project to a product solution.
