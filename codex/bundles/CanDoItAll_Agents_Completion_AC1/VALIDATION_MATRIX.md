Include startup/integration/browser lanes explicitly; an unconfigured gated test is NOT_RUN or BLOCKED, not success.

For a group to pass, the referenced evidence must actually prove its named requirement. A generic unit test cannot pass the native restart or multi-instance group. `tools/validate_handoff.py` checks basic structure only; review actual relevance and authenticity separately.
