# Native application journeys

Use real Web/owners on task-owned data. A scripted remote model is permitted; echoed fake persistence, fabricated approvals, toast-only assertions or API-only navigation replacing required UI are not proof. Keep each final scenario's source/image, IDs, accepted input, UTC scope, operation count and content/hash evidence.

| Journey | Minimum native proof |
|---|---|
| Complete Agents shell | Direct route and every current tab, header loading/failure, HR readiness, exact selected agent/team/profile, redirects and browser Back/Forward; no duplicate default feeding. |
| Usage trio | Actual Agent and SimpleChat calls, consumer/provider/model details from Overview, exact applied query window, native totals including unknown/unpriced/partial coverage and independent dialog lifecycle. |
| Standard Agent chat | New thread, immutable original prompt/model, streaming/transient state, stored transcript and terminal run; reopen original, cancel pending versus close, duplicate-click guard. |
| Context and floating | Open contextual chat from a real Project Structure node; follow/detach and next-turn context, switch source/view, two floating handles, preserve unrelated chat and permissions. |
| Approval/file | Hidden existing-file canary absent from the prompt; real allow and reject; exact project/node/path/overwrite arguments reviewed before approval; non-overwriting write, asset attachment, metadata/content read and native download hash. No unrelated file changes. |
| Runtime/log | Correct run/entry IDs, compatibility/failure context, timeline and metrics; copy sanitization; no private sentinel in DOM/log/URL/media; old dialog cannot control a new run. |
| Capability/team continuity | Create one definition, assign via actual A2 semantics, Verify without overwriting dirty draft, metadata edit preserves current membership, no new member gains permission. Use current test families rather than regenerate all fixtures. |
| Providers | Native default catalog from source, exact source names and opaque route IDs on both clients, default/nondefault persisted choice, no fallback after disable/revoke and unaffected neighbor profile. |
| Voice/Floating | Actual settings owner read/save, deterministic audio synthesis/playback/denial, explicit saved-secondary-failure status, no old playback after retirement, unchanged run lifecycle budgets. |
| SimpleChats | Actual create/edit/open/Send, unavailable shared model value retained/visible by policy, stored transcript, isolated operation scopes, usage/History identity. |
| Workflow | WF1 rich round-trip, Prompt version pinning and a saved accepted-output run; incomplete output remains failure; both preview entry paths test WF1-R1 without replay. |
| Scheduler restart | UI create finite enabled plan, let original fire complete, restart same owned database without pausing, same run count; then future real Quartz fire exactly once. Inspect histories and unchanged source version/admission. |
| Request History | Lazy Search, exact native attempt IDs across scoped/global view, separately authorized content, expired/revoked access and no resurrection after profile change. |
| Neighbor modules | Existing Projects/Resources governed reopen, Workspace navigation/settings and TestLab/Workflow fixtures remain operational without reference regression. |

Read independently from native stores/API where appropriate; metadata-only APIs must not be treated as payload APIs. A native metadata identity plus separately authorized UI content is stronger than weakening the contract to expose content globally.

Build browser helpers around accepted state, not button existence or sleeps: accepted provider/catalog revision, accepted query, committed credential deletion, actual Project owner readiness and server navigation acknowledgement. Preserve old failed attempts and limit retries to a diagnosed correction. A declined fixture preflight is a pre-effect refusal, never a product pass.
