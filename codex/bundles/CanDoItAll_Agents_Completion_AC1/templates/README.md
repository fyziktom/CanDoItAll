# External execution evidence

Copy `evidence.json` outside the sealed package. Record source pair, exact image/build fingerprint, commands, expected/actual discovery, runtime expansion accounting, original attempts and their real artifacts. Credentials/raw transcripts/full error data remain private; report safe IDs, counts and hashes.

A test PASS requires actual executed cases, zero failure/skip and a nonempty exact command/artifact reference. A subsequent pass does not overwrite the earlier failed attempt. A composite group may cite different relevant attempts; explain source equivalence and qualifications. Broad Stable disposition is not a false all-green claim.

A complete presentation closure requires all assigned blockers repaired, no unresolved blocking findings, a complete census, actual consumer proof and verified signed commits. General release readiness remains separate. The verifier cannot authenticate artifacts or semantic coverage. Historical nonblocking qualifications must stay explicit.

Use [the finding template](finding.md) for new complex issues. Raw census may be generated by `tools/inventory_renderers.py`; complete caller/dynamic/asset analysis manually or with available CodeAnalytics before final classification.
