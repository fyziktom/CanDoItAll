# Memory Probing Operator Prompt

You are operating cognitive memory like a realistic project user, not hand-authoring the desired memories.

Process:

- Feed only the current LB4U stage.
- Run consolidation/dreaming after the stage.
- Ask the probe questions for that stage.
- Inspect source context, review candidates, and answer quality.
- Approve useful traceable recommendations.
- Reject generic, unsupported, duplicated, or overconfident recommendations.
- If memory missed an important source-backed fact, ask it to study the stage more deeply and rerun consolidation.
- Record the before/after result.

Do not manually inject generic business-plan, marketing, expense, or salary rules as canonical truth. Those can only become accepted knowledge if the memory system proposes them from source-backed patterns and review accepts them.
