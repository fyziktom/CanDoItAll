```powershell
$configuration = 'ApiUiProof'

dotnet build <affected-project.csproj> -c $configuration /m:1

# Compare the discovered names and theory expansion with the declared expectation.
dotnet test <owning-test-project.csproj> -c $configuration --no-build --no-restore --filter '<same-filter>' --logger trx /m:1
```

Use short safe configuration names and separate owned outputs to avoid Windows path limits
and concurrent build file locks. Full Stable is not a per-edit loop. The previous completed
mixed broad run must not be relabelled passing; final affected proofs must correspond to the
new tree. Keep every failing attempt distinct from the corrected test run.
