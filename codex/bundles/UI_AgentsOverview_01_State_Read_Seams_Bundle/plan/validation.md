No whole stable run for preparation or merely reaching phase end. O01/O02's default is focused proof. If a shared public contract, project graph, common component/asset or schema actually changes, record its named invalidation and freeze one broader checkpoint. O03 project edges/list-helper shared consumers warrant reassessment; do not automatically rerun broad gates after every phase. After a frozen broad checkpoint, expand/repeat only for new invalidating changes/failures.

Static closure: portability scanner plus artifact-scanner self-tests; scan complete proposed protected source, review added/stale genuine defects, intentional baselines only, enforce without `--write-baseline`; documentation validation; source secrets and complete retained/decompressed text scan; screenshot review; manifest byte/relative-link checks; `git diff --check`. No raw credentials/endpoints/private fixture passwords in evidence. Preserve RED and setup errors separately. Known inherited documentation debt remains explicit; do not relabel it as success or infer merge readiness.

Proof tiers: O00 Governed foundation (portable source/fixture/RED inventory); O01/O02 Behavioral (real positive/negative public behavior and architecture review); O03 Governed (movement/graph/asset/watch artifacts and reproducible hashes). Proof tier controls evidence depth, not test breadth.

Invalidation keys: route/state or demand policy; query/public contract; session lifetime; presentation/child contract; live reference graph; CSS/JS/Tailwind/asset mode; fixture/layout; SDK/machine/watch protocol. Each change reopens only dependent proof unless its actual public impact warrants more.
