# Target Solution

The target is the existing Simple LLM Chats module made operationally complete: strongly typed Web contracts, confidential read projections, atomic application/persistence transitions, fully supervised provider execution, evidence-driven recovery, complete durable attempt/SSE evidence, coherent and bounded retention, validated capacity options, safe provider logs, and current source-based release proof.

No new project boundary is introduced. The only planned structural extraction is definition/conversation endpoint ownership inside Web. All other edits remain with their current domain/application/persistence/composition owners.

The target is ready for a later UI-component bundle, but this bundle neither creates nor unlocks UI work as an execution step.
