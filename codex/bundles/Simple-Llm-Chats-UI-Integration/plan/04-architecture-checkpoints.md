# Architecture Checkpoints

## CP0 — After SB01

Pass only when source authority, proof durability, prior closure claims, and user-supplied evidence agree.

## CP1 — After SB05

Required:

- no project cycles;
- neutral project remains backend-free;
- defensive value contracts and generic action model independently tested;
- transient Assistant streaming presentation and Markdown security tests pass;
- ActiveOperationId is exact and profile-fenced;
- targeted Agent component/browser parity passes;
- no Simple Chat UI activation exists.

CP1 unlocks SB06.

## CP2 — After SB10

Required:

- `LlmChats.Ui` is independently testable and free of forbidden references;
- definitions and conversations work through application gateways;
- streaming/cancel/reconnect/recovery proof passes;
- `/chats` large-desktop browser proof passes;
- no floating Agent source change has been made yet, except planned shell contracts that remain inactive.

CP2 unlocks SB11.

## CP3 — After SB11

Required:

- neutral shell has no Agent/Simple backend dependency;
- both contributors test independently;
- All/Agents/Chats and Available/Active behavior passes;
- existing Agent context/affinity/history/close behavior passes;
- Simple Chat focused streaming/reopen/cancel passes.

## FINAL — SB12

One frozen commit, one Stable gate, targeted browser scenarios, final CodeAnalytics architecture review, committed proof, and user handoff.
