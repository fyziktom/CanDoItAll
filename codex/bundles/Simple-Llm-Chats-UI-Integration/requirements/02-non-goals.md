# Explicit Non-Goals

- No Project Structure, project, node, subtree, file, or free-form context attachment.
- No Simple Chat tools, skills, MCP, approvals, Agent runtime, Memory, voice, image generation, or file/image attachments.
- No public website widget, external participant identity, moderation, rate limits, channels, human handoff, or deployment aggregate.
- No mobile, tablet, or small-screen application redesign.
- No rewrite of the durable LLM Chat backend or provider streaming pipeline.
- No replacement of the Agent chat coordinator, execution runtime, or context authority with Simple Chat abstractions.
- No loopback HTTP client from server-side Blazor to its own API.
- No repeated unfiltered Stable or Playwright suite runs.
