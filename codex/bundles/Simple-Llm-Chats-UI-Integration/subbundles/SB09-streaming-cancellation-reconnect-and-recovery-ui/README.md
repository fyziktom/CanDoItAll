## Implementation Steps

1. Follow durable operation event pages through the UI event-session adapter and pure reducer.
2. Coalesce response deltas into one transient Assistant message and refresh canonical state on terminal evidence.
3. Handle duplicate cursors, gaps, retention, invalid cursor, browser/circuit remount, profile lifetime cancellation, and terminal-before-subscribe races.
4. Add explicit Cancel, Reconcile, and evidence-gated Abandon actions; separate them from navigation/window close.
5. Prove a slow deterministic streaming path and ensure follower disposal never invokes cancel.

## Acceptance Criteria

- [ ] Slow streaming updates one transient Assistant message.
- [ ] Refresh/remount reconnects to the same operation.
- [ ] Gap refreshes canonical state without duplicate partial text.
- [ ] Close/dispose does not cancel; explicit Cancel does.
- [ ] Recovery actions are evidence/state gated.
