# Large-Screen-Only Proof Policy

This bundle is runtime/service refactoring. Browser proof is expected to be `N/A`.

Hard policy:
- Do not create small-screen, medium-screen, mobile, phone, tablet, Android, iPhone, or responsive proof artifacts.
- Do not spend time optimizing for small or medium screen.
- If an unexpected UI-visible change appears, stop and record the scope breach.
- If visual proof is explicitly required after such a breach, capture only large desktop/PC proof.
