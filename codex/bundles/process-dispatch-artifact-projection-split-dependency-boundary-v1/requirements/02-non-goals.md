# Non-Goals

- Do not create `CanDoItAll.Processes.Core`.
- Do not move EF entities or migrations.
- Do not create production `IProcessDriverPack`, `IProcessDriverRegistry`, process-driver packages or driver/tool runtime integrations.
- Do not change the projection source-family order.
- Do not remove existing wrapper methods unless all consumers are migrated and focused tests prove compatibility.
- Do not change artifact storage format, external reference key format, projection lineage format, trust status, sensitivity level, or replay context fields.
- Do not touch UI, browser routes, Razor, CSS, JavaScript, TypeScript, screenshots, small-screen, medium-screen, mobile, phone or tablet proof.
