# Large-screen-only Proof Policy

This bundle is service/runtime refactoring only. Default browser validation: `N/A`.

Do not create proof artifacts, screenshot paths, scripts, docs, or test plans containing these viewport targets unless the user explicitly changes the product requirement:

- mobile
- small screen
- medium screen
- phone
- tablet
- iPhone
- Android
- responsive proof

If an unexpected UI proof is required, use only a large desktop PC viewport and record why service tests were insufficient.
