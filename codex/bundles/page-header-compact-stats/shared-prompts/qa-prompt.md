# QA Prompt

Validate the completed bundle against N001-N008:

- On large screens, page headers should be short and compact, with badge stats instead of large stat tiles.
- Header actions should be icon-only with accessible labels and delayed tooltips.
- CRM-HR tab routes should no longer show large first-screen stat tiles.
- Tooltip checks must wait for the 2-second delay and prove the opened tooltip is readable and not clipped.
- Screenshots must be reviewed for height savings, no overlay, no horizontal overflow, and no incoherent wrapping on the large viewport.
