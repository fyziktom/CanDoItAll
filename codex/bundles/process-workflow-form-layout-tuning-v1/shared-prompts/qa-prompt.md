# QA Prompt

Review the changed UI against the raw request, not against the generated images alone.

Check:

- Long process step details are split into intent-level tabs.
- Process child setup editors remain reachable and compact.
- Workflow editor forms are separated into Definition, Node setup, Routes, and Preview/Validation or equivalent tabs, with executor settings reachable from Node setup.
- Existing save, publish, validate, run preview, add/remove step, add/remove role, add/remove artifact, and edge-edit actions are still visible where expected.
- Layout uses existing components and does not introduce a new visual style.
- Desktop and narrow screenshots show readable text, no incoherent overlap, no avoidable lateral overflow, and reachable action buttons.
