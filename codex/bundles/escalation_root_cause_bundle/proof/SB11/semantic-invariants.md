## Production Behavior Artifact Matrix

| Runtime signal | Lifecycle invariant |
| --- | --- |
| `DotNetSolutionSetupRuntimeExecutionResult` | Produced by the runtime-owned executor, consumed by the adapter, and negative-tested for helper failure. |
| `RuntimeOwned:IdempotentSkip` receipt | Produced when target files already exist, preserving repair safety without destructive scaffold regeneration. |
| `workspace_pwsh_run_script` receipt | Produced by the helper invocation for create, repair, and add-test paths; success still requires product readback. |
| `ProductCompletionRequiredFileContentChecksByStep` | Consumed by executor readback and by normal completion gates so file existence alone is not accepted. |

## Architecture

- The executor lives in `Modules.Processes` runtime integration because it adapts process runtime assignments to governed AgentFramework workspace tools.
- The implementation does not move generic deterministic execution policy into Workbench or UI code.
- Adapter partial changes are limited to plumbing the runtime-owned result through existing managed artifact and completion gate flow.
- No new project references were introduced.
