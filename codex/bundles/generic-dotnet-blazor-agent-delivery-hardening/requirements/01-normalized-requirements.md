# Normalized Requirements

- R1: The platform must expose a generic `workspace_dotnet_run` tool through command execution, MAF runtime tools, and the seeded capability catalog.
- R2: Default programming/.NET/QA agents must have scaffold, restore, build, test, run, browser, and evidence guidance that is generic across .NET app types.
- R3: A dedicated Blazor application developer agent must be seeded with Blazor, C#, small JavaScript interop, Playwright, component-library, BaseLib/component MCP, and .NET build/run/test capabilities.
- R4: Active seeded skills and agents must not hardcode calculator, converter, unit-converter, length, temperature, or other sample-topic app requirements.
- R5: Blazor guidance must remain specialized but generic: preserve modern Blazor Web App/SSR hosting rules, component-library preference, typed state, and real browser proof.
- R6: Existing managed catalogs must refresh to the updated seed baseline so running installations receive the new agent and capabilities.
- R7: Validation must include source scans, focused tests, a build, and two live web-app process-flow runs writing results under `C:\programovani\dotnet`.
