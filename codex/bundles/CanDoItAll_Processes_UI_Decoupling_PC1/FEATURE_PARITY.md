## Field-level baseline

Capture all current visible editor fields, command kinds and child surfaces into a working copy of `templates/feature-contract.csv`. Include native-only/unsupported states and the reason they are unavailable. Record screenshots/semantic assertions before extraction where practical. The final mapping names the actual new renderer and native owner; temporary retained slots cannot remain unclassified.

Existing supported function must survive. A deliberate bug fix can change incorrect behavior only with a failing-first/positive-control record and the native compatibility reasoning. Do not turn a security refusal into a working operation or a genuine committed outcome into a generic failure.

No row starts passed. Use an external copy of `templates/evidence.json`; source review and package self-tests do not satisfy product rows.
