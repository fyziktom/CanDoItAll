# Stages of one assignment

Stages are resumable checkpoints, not separate requests. Maintain the shared progress ledger and keep production usable. Continue through all stages unless an actual external prerequisite blocks dependent work; complete independent safe work and report the blocked dimension.

## P0 — Current merge, baseline and impact contract

Record branch/HEAD/tree, dirty work, consumed sibling SHAs and current configuration. Read full current files for all eight renderer families, three route hosts, relevant native clients/file/context/launch owners and tests; review source beyond this package's inspected ranges. Enumerate nested render fragments/dynamic dialogs, routes, query behavior, command catalogues, all editor fields and UI capabilities. Complete the feature contract and list current native owners.

Use CodeAnalytics plus the mandatory union to map tests. Build the native Processes module and affected current Web/composition; run a narrow baseline for existing ProcessWorkspaceShellTests, ProcessRunFilesDialogTests, ProcessRunCancellationActionTests and the selected browser journey after reconciling its current controls/readiness. Keep a baseline failure distinct from a refactor regression; repair a bounded real blocker without swallowing or skipping it. Inspect current DI and actual CI registration before selecting a new project structure.

Do not run the entire application suite or replay the old WB6/live-provider campaign at entry. Preserve the merged demo fixes and working source pair; do not reset to an older reviewed commit.

## P1 — Failing-first state/origin corrections and real boundary

Reproduce R1/R2 first; exercise R3/R4 with controlled ordering. Preserve positive controls. If the current checkout already fixes one, record its passing current control and avoid duplicate code. Add a stable draft/operation model at the actual owner seam, per-view lifetime and honest commit/read-back behavior. Reuse existing projection contracts where suitable; create only the missing light view/intent boundary. Existing cancellation and retained-intent tests remain regression floor.

Wire the first real renderer slice into both native host and minimal independent host. A compile-only empty sandbox is a checkpoint, not a delivered result. Keep remaining real production surfaces alive during subsequent stages.

## P2 — Complete authoring and Exchange

Extract the full catalog/definition editor; every role editor field/dialog/template action; step list, basic/operation/route/role/artifact/subprocess fields; real canvas/gestures/floating windows; template catalogue and every current preview/import action. Keep all eight workspace detail tabs reachable. Preserve editor state across actual server-tab unmounts and native command refresh. Test keyboard/footer submission, raw invalid input, conflicts and post-submit edits under the chosen policy. Close authoring's rendered child closure, not just its root markup.

## P3 — Runtime, Live Processes, files and cancellation

Complete run/launch/control/execution/coordination/evidence views, history/graphs/analytics and operator notes/actions. Complete all four Live tabs, selected/unavailable run handling, hidden run groups, current history windows and dialogs. Extract actual run files and cancellation presentation while keeping native authority/receipts. Prove late success/error/finally/disposal and independent openings. Preserve accepted launch recovery and explicit new intent; no remount or refresh may create a second run.

## P4 — Manager chat, contextual integration and native consumers

Finish real manager-chat/streaming/attachment/voice presentation and current contextual agent publication. Preserve freshness, scope binding and no implicit projection reads. Verify non-run/required-run deep links, focused dialogs and removed/recreated projects. Keep the completed Workbench execution/approval/staffing/launch consumers working through actual native seams; do not re-extract them. Exercise deterministic real-owner agent/workflow/process interaction without claiming external live-model evidence.

## P5 — Complete independent host, production browser and development loop

Finish representative and adversarial scenarios for every in-scope family using the same real children. Verify two simultaneous surfaces, nested overlays, actual canvas/JS, FileBrowser/FileInteraction, charts and conversation UI. Run full native browser journeys with durable IDs/content oracles. Verify clean source and published startup/assets and current Fast/Parity behavior. Measure the representative development loop and compare with Web without hiding source or disabling functionality. Update actual test solution/CI registrations and maintained architecture/testing docs in English.

## P6 — Freeze, integration and qualified closure

Freeze the final code/configuration/source pair after focused tests stabilize. Refresh CodeAnalytics/consumer selection for the final delta. Run final focused coverage, required production/browser/publish gates, the justified one broad Stable checkpoint and mandatory portability enforcement. After any fix, rerun invalidated lanes; do not declare an older candidate's results current.

Produce an exact residual render/effect census: each current native Razor/partial/dynamic child is either a legitimate thin/native owner/composition/context host, a classified dormant compatibility surface, or an unfinished active renderer. The last category must be empty **inside PC1**. Record any additional whole-repo residual candidate without implementing an unauthorized third module. Finish the feature matrix and use templates/closure.md for explicit structural/native/browser/assets/performance/gate status. Do not call an S0-only or blocked proof state complete.
