# Self Review Checklist

## Architect
- [ ] Bundle expands Core only by pure rule/read-model families.
- [ ] Side-effectful orchestration remains module-local.
- [ ] Driver work remains docs/tests-only.

## QA
- [ ] Focused parity tests are planned for every production move.
- [ ] No UI/mobile proof is requested.
- [ ] Completed validator required.

## Manager
- [ ] Subbundles are broader and meaningful, not micro-slices.
- [ ] Critical gates occur every few subbundles.
- [ ] Raw user request remains traceable.
