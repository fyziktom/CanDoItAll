This matrix is required final evidence for this slice, not a demand to rerun every test after
each edit. Source-inventory existing tests first; adapt exact filters and discovery counts.
Use current production entry points, not substitutes registered into the shipped application.
A skipped/inapplicable environment lane must remain explicit. No broad all-green claim from
focused results or inherited reports.

inventing duplicate work. Class names discovered from old branch search are navigation hints,
