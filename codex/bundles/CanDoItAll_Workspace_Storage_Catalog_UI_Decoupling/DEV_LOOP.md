not a reason to report hot reload that did not happen. Compare only like endpoints: interactive
readiness is not interchangeable with first successful persistence.

sandbox must not test network connections, resolve credentials or repeatedly enumerate DB
catalogs. Preserve existing owner bootstrap-on-read behavior rather than misreport it as a
new effect-free store. Optimize redundant reads only at a justified local boundary, without
creating a shared cache that crosses profiles or imposes new module coupling.

small backend-free feature loop, not a preselected speedup ratio. Preserve regular app port
5032. Use task-owned loopback ports/PIDs, a separate short build configuration, private fixtures
