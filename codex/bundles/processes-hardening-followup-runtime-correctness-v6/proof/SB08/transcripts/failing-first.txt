- A recorded required artifact could therefore satisfy manual completion by metadata alone while the actual storage-backed content remained unread.
- Automated finalization already used the storage-backed reader, so manual/API and automated completion had divergent validation depth.

Red-team test added:
- `TransitionStepAsync_SB08_INV_001_rejects_malformed_storage_backed_json_required_artifact_on_manual_completion`

Behavior under test:
- Create a FileSystem storage catalog entry outside the workspace root.
- Write malformed JSON into that storage location.
- Record the required process artifact with a managed storage reference JSON.
- Attempt manual completion.
- Expect `processes.step-completion-invalid-required-artifacts` and a malformed JSON diagnostic.

This proves manual completion cannot satisfy required JSON artifacts from metadata only.
