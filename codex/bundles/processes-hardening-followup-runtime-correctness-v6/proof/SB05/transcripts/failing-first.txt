# SB05 failing-first.txt

Red-team target: a step blocked for its own missing required output artifact must not be classified as a missing upstream input.

Pre-fix source behavior:
- `ProcessStepRunBlockState.InferBlockReasonCode` mapped text containing `missing required artifact` or `required artifacts remain missing` to `MissingUpstreamArtifact`.
- That caused recovery options to include upstream materialization even when the missing artifact was the current step's own output contract.

Red-team tests added:
- `ProcessStepRunBlockState_SB05_INV_003_does_not_infer_own_required_artifact_as_upstream`
- `TransitionStepAsync_SB05_INV_001_persists_own_output_artifact_contract_block_cause`
- `TransitionStepAsync_SB05_INV_002_persists_upstream_input_materialization_block_cause`

Expected failure before fix:
- Own missing artifact would persist as `MissingUpstreamArtifact` and include `WaitForArtifactMaterialization`.
