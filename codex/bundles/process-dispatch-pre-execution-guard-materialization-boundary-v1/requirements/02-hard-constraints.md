# Hard Constraints

- No Process Core project.
- No production driver API.
- No driver registry.
- No package split.
- No UI changes.
- No small/medium/mobile proof.
- Preserve existing wrappers until tests prove replacements.
- Keep side effects explicit.
- Do not change external reference key, fingerprint, journal event type, transition request, or rerun directive semantics without a failing-first test and explicit architectural approval.
