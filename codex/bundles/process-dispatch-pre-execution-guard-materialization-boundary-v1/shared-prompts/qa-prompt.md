# QA Prompt

Review implementation against these traps:

- side effects hidden inside pure planners,
- changed fingerprint/journal/rerun directive,
- direct Process Core or driver API introduced,
- broad cleanup outside dispatch boundary,
- dropped existing wrapper behavior,
- mobile/small/medium proof artifacts,
- no failing-first or source-scan proof for critical movement.

The final report must be evidence-backed, not prose-only.
