The uploaded repository contains the current CanDoItAll Agent Framework integration.
The goal is to thoroughly inspect how agents are currently implemented with Microsoft Agent Framework, identify missing or unstable architecture/implementation pieces, and provide an execution-grade Codex bundle with detailed subbundles so Codex can implement and test the improvements.

Important context from the requester:
- The current system already has advanced process-driven multi-agent behavior.
- Agents already managed to create a simple calculator application through cooperation of multiple agents controlled by a process.
- The direction is basically correct.
- The next goal is to improve and stabilize architecture and implementation, especially where MAF already offers better native mechanisms.
- A previous structured-output recommendation was valuable because the project did not originally enforce agent output formats correctly.
