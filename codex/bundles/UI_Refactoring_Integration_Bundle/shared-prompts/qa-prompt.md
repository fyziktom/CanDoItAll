# Shared QA Prompt

Review the completed subbundle as an independent senior reviewer.

Check:

1. scope matches the subbundle and no v2 content entered,
2. conflict decisions preserve current development,
3. static assets exist in a clean source checkout,
4. Components/FileTools ownership remains correct,
5. package versions are coordinated,
6. source and package dependency modes were not mixed,
7. DOM/CSS/test selectors use stable semantic hooks,
8. approval changes were semantically reviewed,
9. browser proof uses supported large desktop,
10. skipped or unavailable proof is explicit,
11. no unrelated refactor is hidden in generated files,
12. progression gate is actually satisfied.

Record blockers, non-blocking observations, and the exact evidence reviewed.
