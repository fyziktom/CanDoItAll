## Important Existing Strengths

The existing bundle already contains these architecture concepts and should preserve them:

- durable memory is source/canonical/graph/episode/procedure/probe evidence, not Qdrant,
- Qdrant is a rebuildable projection,
- recall is staged and traced,
- source provenance is mandatory,
- probing feedback is evidence and not direct truth mutation,
- Epistemic Drive preserves multi-dimensional knowledge need vectors,
- learning proposals require approval,
- distributed idle workers cannot mutate authoritative memory.
