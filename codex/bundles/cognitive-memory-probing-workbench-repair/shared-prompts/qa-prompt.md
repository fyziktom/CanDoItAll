# QA Prompt

Validate that a user can inspect and repair Cognitive Memory through probing:

- start a project-scoped probe session;
- ask an arbitrary project question;
- see answer sections, source refs, warnings, and recall trace metadata;
- submit typed feedback with notes/correction text;
- create a review-gated repair candidate;
- approve the review item and see memory updated through the normal review path;
- create/replay a regression test where requested;
- prove UI readability and action visibility on desktop and narrower viewport.
