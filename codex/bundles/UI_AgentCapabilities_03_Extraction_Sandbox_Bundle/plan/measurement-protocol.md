# Direct watch measurement protocol

PLANNED, not executed. SB00 must produce a valid full-app baseline before SB01 moves any source. If direct watch cannot be observed, stop before movement with the exact blocker; do not relabel old catalog or fixture runs.

## Freeze and comparability

Record UTC/monotonic clocks, machine/OS/CPU, actual SDK from global.json and dotnet --info, local and independently read remote SHA, dirty diff/hash, sibling revisions/status and live source mode, power/load conditions, exact commands/environment, asset build commands/roots/mode/hashes, ports and process ownership. Freeze safe fixture JSON/hash/IDs/counts/kinds/proofs, requested agent/scenario and 1600x1000 viewport. Use that matched rendered fixture throughout; no arbitrary external diagnostic or chat prompt.

Compare four configurations sequentially on the same machine: pre-extraction full app, post-extraction full app, sandbox Parity, sandbox Fast. Only one direct watch host owns edited shared dependencies at a time. SDK, siblings and source mode stay the same. Parity uses the real production theme; Fast uses its audited pipeline. Pipeline differences are an explicit experimental factor, not silently equal conditions. Record browser/cache/warm-up differences.

Cold startup is separate, at least three runs per configuration, from process launch to explicit interactive-ready/fixture-visible criterion. Report asset generation and prerequisite seeding separately; distinguish process-cold, filesystem-cache and restore-cold conditions. Do not delete global caches. Full-app startup-profile confirmation is a recorded setup stage, not an unexplained omission.

## Warm matrix

Before timing freeze three distinct visible edits for each category. Use actual moved source and equivalent before/after targets, never unrelated no-op files. Suggested bounded probes: three separate visible Razor labels/markers in Surface/list; three C# presentation outputs such as kind label/count summary/metadata formatter; three scoped CSS declarations affecting measured heading/list/card geometry or color. Freeze exact deltas and DOM/computed-style predicates in SB00; save original bytes/hashes. Do not change permission/persistence/query/fixture identity. Add no permanent production probe logic.

Run each of nine edit definitions at least three times per configuration: 27 forward observations per host, at least 108 overall. Restore original bytes after each observation and retain the reverse/undo measurement separately. An undo is not a forward repetition. Keep failures; retry only with documented cause and preserve both attempts. Before/after paths may differ but the visible change must be equivalent.

Start timing after the source bytes are flushed and record changed hash. End at the specific browser-visible DOM/computed-style predicate in the real interactive specimen. Retain watch stdout/stderr, browser navigation/reload timestamps, runtime PID, DOTNET_WATCH_ITERATION and available hot-reload probe generation. Automation observes direct dotnet watch. Do not silently substitute a managed watcher refresh loop or manual reload.

Classify from evidence: hot reload (visible update, no navigation/restart), browser reload (navigation/refresh, same process), restart (new process/watch iteration then visible), failure (timeout/build error/disconnect/no visible change). A server generation alone is not edit-to-visible proof. Retain event ordering; label ambiguous data inconclusive rather than selecting the fastest event. If a supported edit needs restart, count its complete latency.

## Report and restoration

Raw samples contain host/mode/category/edit ID/repetition/direction/timestamps/duration/classification/reason/hash/evidence paths. Per matched group report successful count, failures, minimum, maximum, range (max-min), median. Never hide failures inside a successful-only headline. Report cold separately; explain whether spread/restarts support improvement. Smaller graph/CSS alone is not a measured benefit; promise no percentage.

Restore only the exact owned measurement files after checking current bytes. Concurrent edits cause a stop, never overwrite. Stop only owned watchers/processes; keep compact raw and negative evidence. Verify restored source/assets and sibling status. No reset/clean/history rewrite or deletion of user runtime data. Logs must contain no secrets or personal workspace content.
