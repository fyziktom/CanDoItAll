# QA Prompt

Review the completed subbundle against:

- Did it preserve previous MAF/tool-provider decoupling?
- Did it avoid premature Process Core extraction?
- Did it avoid driver-pack work?
- Did it keep public tool names stable?
- Did it preserve access, approval, receipt, and artifact lineage behavior?
- Did it include source assertions, tests, and failure-mode proof?
- Did it avoid mobile/small/medium proof?
- If browser proof exists, is it large-screen PC only and relevant?

Reject shallow proof such as compile-only claims for execution movement.
