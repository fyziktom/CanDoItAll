# Large-Screen Proof Policy Inventory

For every subbundle, record one of:

- `N/A - no UI or host-visible route changed`
- `Large-screen PC only - route <route>, viewport <size>, screenshot <path>`

Forbidden proof labels:

- `mobile`
- `small screen`
- `medium screen`
- `responsive optimization`
- `phone viewport`
- `tablet viewport`

Any proof artifact that uses these forbidden proof labels must reopen the subbundle unless the user explicitly changes scope.
