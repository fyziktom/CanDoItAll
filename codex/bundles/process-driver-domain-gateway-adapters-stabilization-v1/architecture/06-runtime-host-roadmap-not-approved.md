# Runtime Host Roadmap - Not Approved

## Decision
A production runtime host is not approved in this bundle.

## Missing prerequisites
- Audit persistence.
- Capability policy enforcement outside tests.
- Sandbox boundary.
- Command/external-call allowlist.
- Timeout policy.
- Secret masking for captured outputs.
- Runtime lifecycle owner.
- Approval/authorization model.
- Failure semantics.
- Backpressure and cancellation.
- Red-team tests for mutation denial.

## This bundle may only update docs and tests that keep runtime host as future work.
