# QA / Red-Team Prompt

Reject the implementation if:
- gateway exposes generic lane dispatch or object payloads;
- domain drivers or adapters can mutate state or call external systems;
- Core references drivers;
- drivers reference Modules/Infrastructure/AgentFramework/EF/UI/storage/workspace;
- proof is report-only without command transcripts;
- full-unit debt is hidden rather than classified or burned down;
- browser validation is added for runtime-only work instead of failing UI drift.
