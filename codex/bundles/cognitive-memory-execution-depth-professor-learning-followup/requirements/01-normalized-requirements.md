# Normalized Requirements

## R-01 Execution-depth hardening

Update bundle execution and validation skills so semantic adequacy, adversarial tests, and anti-simplification proof are mandatory for deep architecture bundles.

## R-02 Validator proof-depth hardening

Extend bundle validation and/or add a proof-depth auditor so a completed bundle cannot pass only because tables and statuses are filled.

## R-03 Regression-first cognitive corpus

Add failing-first tests that expose the current shallow implementation before production changes are made.

## R-04 True composite multi-key clustering

Replace single-primary-key grouping with bounded composite clustering based on weighted pair/edge evidence, negative separation signals, and stable cluster identity.

## R-05 Deep dreaming and aggregate validation

Replace template dream output with structured claim synthesis, claim-level support checks, near-duplicate detection, conflict handling, and calibrated aggregate application.

## R-06 Professor/curator learning lifecycle

Represent professor input as learning anchors that can be compared, applied, assimilated, and faded only after independent derived knowledge proves internalization.

## R-07 Recall synthesis and reference-on-demand

Return concise query-shaped briefs by default, preserve claim/phrase-level provenance internally, and expose references only when requested or diagnostic mode is enabled.

## R-08 Refactor boundaries

Split large services into testable collaborators and keep contracts/versioning explicit.

## R-09 End-to-end proof

Provide an end-to-end scenario where professor correction, dream assimilation, aggregate validation, recall brief, and reference expansion all work together.
