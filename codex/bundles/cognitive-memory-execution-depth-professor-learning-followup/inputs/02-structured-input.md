# Structured Input

## Non-negotiable outcome

The module must not merely store and retrieve memories. It must support a reliable cognitive loop:

1. source-backed memories are clustered by multiple meaningful signals;
2. dreaming/consolidation synthesizes useful aggregate knowledge instead of concatenating context;
3. aggregate claims are validated against provenance and conflict state;
4. professor/curator knowledge acts as a high-trust learning anchor that is compared, assimilated, and faded only after the system has really internalized the knowledge;
5. recall returns a helpful brief by default and detailed references on demand.

## Explicit exclusions

- No economic governance model.
- No attention-market model.
- No resource-pricing policy.
- No live LLM dependency in deterministic proof unless explicitly separated behind provider abstractions and mocked in tests.

## Process correction

The first implementation phase must harden the execution skills and validators. The agent must install and use those updates before modifying cognitive-memory code.
