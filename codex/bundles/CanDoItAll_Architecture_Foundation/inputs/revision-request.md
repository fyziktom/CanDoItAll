# Revision request — English translation

The existing package looks good, but safe contributions by agents, workflows, and processes to modules other than Project Structure are not sufficiently specified. HR can edit agents and should also edit Simple Chats definitions, which is currently missing, and CRM resources. Similar needs exist for Scheduler and process-related agents.

The reverse path is also required: an agent may need CRM people to create a task, or a Resource from another module. Recheck the entire design and fill these gaps.

Translate the whole package to English so Codex does not generate Czech implementation bundles. Return a complete new ZIP, not merely an addendum or patch.
