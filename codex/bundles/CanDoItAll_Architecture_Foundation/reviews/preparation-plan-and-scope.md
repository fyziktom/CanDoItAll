# Preparation plan and scope

The revision followed these workstreams: inspect the original complete archive and preserve its file/catalog inventory; query the actual branch and read targeted primary sources for HR/CRM, Scheduler, Simple Chats, runtime tools, Processes, and Resources; identify unsupported assumptions; translate all normative prose and machine-readable fields; extend destination-owner operation/query rules, managed profiles, and recovery; regenerate module cards and proof links; review architecture and QA consistency; fix findings; validate language, references, inventory, and integrity; create and revalidate the full ZIP.

This was documentation preparation. No repository writes, application build, schema migration, UI test run, live provider call, or runtime execution occurred. Existing current-code observations are bounded by sources.json; the HR administration-service read was partial/truncated. Original source pins are preserved rather than silently refreshed.

Review perspectives were performed in the same preparation workflow, not by a separately independent human or model. Their purpose is to find internal contradictions and unsafe omissions; implementation correctness still requires actual scoped proof.
