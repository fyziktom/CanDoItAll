# Recipe Pantry Planner

Build a local pantry and recipe planner.

## Requirements
- Use a client-only static web app.
- Allow adding pantry ingredients.
- Provide a small built-in recipe list.
- Filter or rank recipes by available ingredients.
- Allow adding missing ingredients to a shopping list.
- Persist pantry and shopping list locally.

## Constraints
- Keep the implementation generic and scoped to this scenario input.
- Do not use hidden scenario-specific process instructions.
- Keep comments in source code in English.
