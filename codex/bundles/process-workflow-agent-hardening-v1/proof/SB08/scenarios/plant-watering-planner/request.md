# Plant Watering Planner

Build a local planner for house plants and watering schedules.

## Requirements
- Use a client-only static web app.
- Allow adding a plant name, room/location, watering interval, and last watered date.
- Show next watering date and overdue status.
- Support marking a plant as watered today.
- Persist data locally.
- Do not use external calendar APIs.

## Constraints
- Keep the implementation generic and scoped to this scenario input.
- Do not use hidden scenario-specific process instructions.
- Keep comments in source code in English.
