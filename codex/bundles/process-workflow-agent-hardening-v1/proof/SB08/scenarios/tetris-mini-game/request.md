# Tetris Mini Game

Build a small static Blazor web Tetris-style falling-block game.

## Requirements
- Use a client-only static web app.
- Render a visible game board.
- Support arrow keys and W/A/S/D for movement/rotation where practical.
- Track score and best score locally.
- Do not add backend or authentication.
- Include simple responsive layout.

## Constraints
- Keep the implementation generic and scoped to this scenario input.
- Do not use hidden scenario-specific process instructions.
- Keep comments in source code in English.
