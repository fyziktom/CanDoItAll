# Study Kanban Flashcards

Build a local study board with flashcards that move through learning states.

## Requirements
- Use a client-only static web app.
- Allow adding a flashcard question and answer.
- Show columns such as New, Learning, Review, Mastered.
- Allow moving a card between columns.
- Support reveal/hide answer.
- Persist data locally.

## Constraints
- Keep the implementation generic and scoped to this scenario input.
- Do not use hidden scenario-specific process instructions.
- Keep comments in source code in English.
