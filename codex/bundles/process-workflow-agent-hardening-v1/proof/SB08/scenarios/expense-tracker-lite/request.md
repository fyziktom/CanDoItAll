# Expense Tracker Lite

Build a simple local expense tracker for adding expenses and viewing totals by category.

## Requirements
- Use a client-only static web app.
- Allow adding expense amount, category, description, and date.
- Show total amount and category totals.
- Support deleting an expense.
- Persist data locally.
- Do not connect to banking or external APIs.

## Constraints
- Keep the implementation generic and scoped to this scenario input.
- Do not use hidden scenario-specific process instructions.
- Keep comments in source code in English.
