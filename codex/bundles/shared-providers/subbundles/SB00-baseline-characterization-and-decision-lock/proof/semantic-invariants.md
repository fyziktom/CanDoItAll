## Semantic gate decision

Pass for SB00 characterization. Positive proof exercises real mapping/registry/driver behavior;
negative and adversarial proof rejects reversed dependencies, cycles, internal HTTP DTO reuse,
invented Azure manifests, legacy-runtime misclassification, and custom-path loss. This decision
unlocks only the planned next subbundle and is invalidated by any project graph, connector
registry, mapper, provider runtime, or test-selection change.
