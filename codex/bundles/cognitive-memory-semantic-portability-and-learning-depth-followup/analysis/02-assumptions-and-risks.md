# Assumptions And Risks

## Working Assumptions

- Codex will execute this bundle from a full repository checkout and can modify both production code and bundle workflow skills.
- Existing cognitive-memory tests may pass while deeper semantic requirements remain unmet.
- Deterministic algorithms are preferred for acceptance tests; optional LLM-based services must be behind interfaces and must not be required for unit test success.
- The repository may be moved between Windows, WSL, Linux containers, and CI runners, so proof artifacts must not rely on one machine's absolute path layout.
- Economic governance and memory resource economics remain intentionally out of scope.

## Critical Path Risks

- Codex may treat tests as the only target and hard-code around the current fixtures rather than implementing general behavior.
- Cross-project clustering could accidentally merge restricted or unrelated memories if project-boundary rules are loosened without access-policy guards.
- Stronger approximate candidate discovery may become too expensive unless it is bounded per record and measurable.
- Deeper dream validation may over-route useful aggregates to review if the rule set is too strict or not explainable.
- Professor-anchor fading could retire human source truth too early if mastery evidence remains keyword-based.

## Validation Risks

- A completed bundle can still pass on the developer machine but fail in a different environment if proof paths are not portable.
- A test can fail-first and then pass without proving the requested behavior unless the test is tied to a named semantic invariant.
- Anti-stub scans can miss hard-coded fixture logic that has no obvious TODO or NotImplemented marker.
- Recall synthesis can look concise while silently dropping caveats or lineage needed for trust.

## Reopen Triggers

- Completed-stage validation fails after moving the bundle to another repo path, WSL, Linux, or CI.
- `CrossProjectWeekly` produces only same-project clusters or cannot explain cross-project policy guards.
- A dream aggregate combines unrelated claims into one claim because they share the same primary cluster key.
- A professor anchor can assimilate based on keyword text rather than durable mastery/use/integration events.
- A recall brief statement cannot be traced to exact supporting aggregate claim IDs and original source maps.
- Any critical subbundle closes without a semantic invariant contract, failing-first transcript, passing transcript, changed-file hash, and red-team negative proof.
