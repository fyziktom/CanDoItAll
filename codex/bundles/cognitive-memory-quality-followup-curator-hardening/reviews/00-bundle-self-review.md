- Every major finding has an owning subbundle and proof method.
- The bundle requires failing-then-passing tests for the riskiest gaps.
- UI/browser proof is required only where the implementation touches visible curator/quality surfaces.

## Manager Review

- The bundle is large but decomposed into coherent phases.
- Critical gates prevent downstream work from building on weak clustering or unsafe curator corrections.
- The bundle is ready for Codex execution as a follow-up implementation package.
