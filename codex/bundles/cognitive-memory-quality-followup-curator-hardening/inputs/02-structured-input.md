# Structured Input

## Goals

- Prove whether the implementation is deep enough for robust cognitive memory behavior.
- Repair clustering so it uses weighted multi-key evidence rather than broad single-key groups.
- Make dreaming behave like real consolidation: compare, abstract, aggregate, validate, and preserve claim-level provenance.
- Make recall output useful to agents/users by synthesizing a concise brief instead of dumping raw memory internals.
- Make curator/professor learning safe, targeted, and useful for cluster/dream improvements.

## Hard Constraints

- Keep economic memory governance, attention pricing, memory budgets, and similar models out of this bundle.
- Do not weaken existing policy, access-level, redaction, source provenance, or mutation audit protections.
- Do not allow curator trust to bypass target ambiguity checks.
- Do not expose full scores, internal traces, or raw references by default in agent-facing recall briefs; references must remain available on demand.
- All source code comments added by implementation must be in English.

## Review Hypothesis

The implementation likely completed structural plumbing but still lacks the quality depth needed for reliable cognitive memory. The highest-risk areas are broad clustering, shallow dream candidate generation, overconfident aggregate application, unsafe curator correction targeting, and lack of professor-anchor assimilation.
