# Execution report template

Use only after future authorized execution. Do not pre-fill success.

## Scope and source

Phase, proof tier, status, R/B/F coverage, source SHA/dirty state, sibling identities/mode, environment, actual changed files, and deviations from planned scope.

## Behavior and architecture

Baseline behavior oracles; preserved versus safeguard versus existing defect; chosen responsibilities/contracts/lifetimes; public type/constructor/subtree dependencies; UI composition decision; simpler alternatives and cost.

## Validation

Exact fully qualified test methods/data cases and derived expected discovery; actual discovery; build/test commands and exit codes; real operation/adapter/production composition evidence; controlled failure/stale/version outcomes; browser interactions/screenshots/console where applicable.

For governed closure include stable and portability no-write results and machine-readable artifact manifest/hash validation. Explain every missing or invalidated result.

## Recovery and follow-up

Reopened phases, proof invalidation, source checkpoint/recovery, disposable-data cleanup, remaining blocker and owner, current watch baseline and concrete extraction/navigation handoff.
