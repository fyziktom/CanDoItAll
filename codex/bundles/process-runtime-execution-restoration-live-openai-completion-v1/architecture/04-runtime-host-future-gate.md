# Runtime Host Future Gate

A runtime host may become necessary later for execution-capable domain drivers, but it is not required to restore current process execution.

## Not approved now
- runtime host;
- registry;
- selector;
- DI auto-registration;
- manager command;
- scheduler/workflow driver hook;
- execution-capable driver.

## Future approval prerequisites
- lifecycle owner;
- audit persistence;
- sandbox;
- allow-list;
- authorization and revocation;
- emergency stop;
- failure handoff;
- compatibility/versioning;
- full source-backed runtime E2E already green.
