# QA Prompt

Validate that the final state proves real process runtime usability, not just report completion.

Check:
- app starts;
- UI/API/project-structure can start a process;
- run lifecycle persists;
- dispatch/finalizer/artifacts advance;
- MAF/direct-agent/workflow routes work;
- `.NET` and business-analysis scenarios complete;
- live OpenAI smoke is opt-in and safe;
- scheduler/workflow-origin starts use process services;
- run detail/recovery UI is visible on large desktop;
- no transient bundle-path coupling;
- no runtime-host/registry/selector/DI/manager hook drift.
