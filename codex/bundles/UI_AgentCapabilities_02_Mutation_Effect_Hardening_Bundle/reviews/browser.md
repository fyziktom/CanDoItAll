## Reproduction

Copy the three fixture recipe files, removing their .txt suffix, into `.mcp-state/capa02-browser-fixture`; paths in the csproj are relative to that owned directory. Build Release with the installed .NET 10.0.303 SDK and live siblings. Run the resulting CapabilitiesBrowser.dll with the repository root as its last argument. It creates a disposable PostgreSQL profile and workspace, exposes the full app on loopback 5273 and controls on loopback 17301. Set CAPA_PLAYWRIGHT to the locally installed Playwright package (tested 1.61.1), then run the retained browser script with an empty output directory. Wait for FixtureReady before starting. Ports must be free; do not stop unrelated owners. POST /fixture/stop disposes only this fixture and its test environment. Test authorization overrides belong solely to this isolated host. This is browser behavior proof, not watch/performance evidence.
