# Subbundle Authoring Contract

Existing numbered phase READMEs are the executable preparation contracts. This reference
describes how to add or revise one only if accepted scope changes; it is not another phase,
an unfinished example or authorization to implement.

Use these sections in order, with concrete content and no empty scaffold fields:

1. Status: distinguish preparation, execution, entry and closure; record Not started until real work.
2. Objective and Covered Inputs: exact user outcome and N/R IDs.
3. Prerequisites: completed gates, current source drift, fixtures and required authorization.
4. Exact Source References: real file links/line anchors; mark proposed types/files as proposed.
5. UI Composition Contract when relevant: shared components, surface/form authority, viewport/scroll/focus.
6. Deliverables and Implementation Steps: minimal ordered edits with named owners.
7. C# Architecture Impact, Boundary Ownership, Dependency Direction and Pattern Decision.
8. Testability Contract, Partial Class Policy and Architecture Proof Required.
9. Dependency Impact: exact downstream phases and invalidation.
10. Validation Depth: Standard/Behavioral/Governed tier, project/filter, named expected discovery,
    selection reason, invalidation keys and explicit broad-gate decision.
11. Acceptance Checklist and Proof Required: observable positives/negatives, real producer/consumer
    evidence and proof/SBxx paths; do not pre-check unexecuted conditions.
12. Browser Validation Logging where relevant: route, desktop1920x1080, explicit actions/assertions,
    normal/overlay screenshots and written visual review.
13. Scope Exceptions, Do Not Do, Progression Gate and Reopen Triggers.

Use canonical bundle/subbundle validation and the architecture guard after editing. Preserve
raw input traceability and the execution report table contracts. Prefer extending an existing
phase/test fixture to inventing another layer or redundant test. New scope needs an updated
dependency map and user authorization where it changes the requested work.
