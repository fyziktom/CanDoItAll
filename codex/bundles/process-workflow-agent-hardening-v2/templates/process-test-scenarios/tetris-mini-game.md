# Scenario Packet: Tetris Mini Game

Build a simple client-only Blazor WebAssembly PWA mini Tetris-like falling-block game.

## Required Behavior

- 10 x 16 board.
- Buttons and keyboard controls for left, right, rotate, and drop.
- Score increases after drop.
- Best score persists in local storage after reload.
- Desktop and mobile layouts remain usable.

## Forbidden Scope

- No backend persistence.
- No external game engine.
- No scenario-specific production template branching.
