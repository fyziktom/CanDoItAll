# Scenario Packet: Study Kanban Flashcards

Build a client-only Blazor WebAssembly PWA for flashcards with kanban-style learning states.

## Required Behavior

- Add question and answer.
- Reveal answer.
- Move card from New to Learning to Mastered.
- Persist card state after reload.
- Show counts per column.

## Forbidden Scope

- No external education API.
- No login.
- No server state.
