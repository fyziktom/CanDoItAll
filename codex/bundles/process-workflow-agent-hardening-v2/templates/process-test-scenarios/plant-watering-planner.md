# Scenario Packet: Plant Watering Planner

Build a client-only Blazor WebAssembly PWA for plant watering reminders.

## Required Behavior

- Add plant name, room, watering interval, and last-watered date.
- Calculate next due date.
- Mark overdue plants clearly.
- Mark a plant watered and update status.
- Persist plants in local storage.

## Forbidden Scope

- No calendar integration.
- No notifications.
- No backend service.
