SB16 source assertions

Typed role model:
- src/CanDoItAll.Processes.Projections/ProcessDefinitionRoleEditorProjectionContracts.cs defines typed role keys, template action keys, editor version tokens, executor kinds, workflow preference kinds, project assignment kinds, override statuses, command kinds, lint sections, and step-role responsibility kinds.
- Executor preference is represented by ProcessDefinitionRoleExecutorKind, not UI string parsing or free-form storage.

Application boundary:
- src/CanDoItAll.Processes.Application/ProcessDefinitionRoleEditorProjectionService.cs owns role editor projections and typed commands: AddRole, SaveRole, ApplyTemplate, DeleteRole.
- Mutating commands validate expected version tokens; stale AddRole, SaveRole, ApplyTemplate, and DeleteRole commands are rejected with processes.definition.role.version-conflict.
- Role template actions preserve template source/snapshot/override metadata instead of dropping conflict/customization context.

Template boundary:
- src/CanDoItAll.Processes.Templates/ProcessTemplatePackLoader.cs loads role usages, role resources, role template actions, and step-role bindings from the template pack.
- src/CanDoItAll.Processes.Templates/ProcessTemplateDocuments.cs registers source-generated JSON metadata for role resources and role template action arrays.

UI boundary:
- src/CanDoItAll.Modules.Processes/Components/ProcessDefinitionRoleEditorPanel.razor receives a ProcessDefinitionRoleEditorProjection and emits ProcessDefinitionRoleEditorCommand values.
- The role panel does not inject projection clients, load files, parse template JSON, access runtime services, or access persistence.
- src/CanDoItAll.Modules.Processes/Components/ProcessWorkspaceShell.razor composes the role editor after the definition editor and preserves RoleEditor when definition save/publish returns an editor projection without nested role state.

Downstream foundations:
- ProcessDefinitionStepRoleBindingProjection and ProcessStepRoleResponsibilityKind provide the SB18 step-role binding contract foundation.
- Role executor, project assignment, allocation, fallback, approval, and template metadata are available for SB21 launch-planning readiness work.
