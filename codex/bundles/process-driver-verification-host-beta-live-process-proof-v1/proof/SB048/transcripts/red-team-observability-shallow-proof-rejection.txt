# Gate P Red-Team Rejection

Rejected shallow closure patterns:
- A string-only denial message with no typed `ProcessVerificationHostDenialCode` and no typed failure category.
- A success-only diagnostics test that never exercises denied host paths.
- A manager readback DTO that omits denial category, denial code, audit record id, audit counts, observation hash, or no-mutation flags.
- Treating diagnostics, response counts, or aggregate observations as approval for process mutation.
- Adding observability through generic process-driver host, runtime registry, selector fallback, DI hook, manager command, scheduler hook, workflow hook, endpoint mapping, or mutation-capable flags.

Required positive proof retained:
- Host denials include category, reason code, message, audit record, no-mutation flags, and identity fields.
- Manager readback projects denied verification attempts with category, code, message, audit readback, zero diagnostics, zero responses, and mutation-denial flags.
- Source scans reject generic driver-host hooks and mutation-allowed observability drift.
