# Implementation Prompt

```text
Execute exactly one dependency-ready subbundle from bundle://subbundles.

Outcome: deliver the subbundle's observable behavior while preserving the bundle's Storage-first order, target dependency direction, explicit authority/effect boundary, large-desktop-only UI policy, and smallest-correct-change rule.

Before editing:
- read the root README, phase plan, architecture checkpoints, selected README, current execution report, and owned requirements/raw notes;
- run the subbundle-validator entry gate against current repositories;
- verify prerequisite proof is still trusted and exact source references still identify the owners;
- for architecture work use CodeAnalytics plus exact source/csproj reads; for UI call Components MCP before structure/CSS and use the managed watch plus one persistent Playwright page;
- stop and repair/reopen when a prerequisite, package hash, API, dependency, authority, or source anchor is contradicted.

Implementation:
- make the smallest cohesive change owned by this subbundle;
- use typed contracts/identifiers/options; fail unsupported behavior explicitly; mask sensitive logs;
- add no service locator, last-wins/default fallback, magic command/key strings, new page partial, or behavior in an already broad UI/composition owner;
- do not start another subbundle or broaden viewport/provider/format scope.

Proof:
- run exact affected builds/tests/format and architecture/dependency checks;
- satisfy the declared Standard/Behavioral/Governed tier, including semantic positive and meaningful negative behavior;
- for Governed work create portable proof manifest/invariants/transcripts/hashes/anti-stub artifacts;
- for UI prove real production wiring at 1900x1200 and 1440x900, inspect screenshots, record DOM/geometry/scroll/overlay/console/network findings;
- run csharp-architecture-review-gate when relevant and the subbundle-validator closure gate.

Update durable state while evidence is fresh: selected README status, execution-report gate/browser/semantic/raw-note rows, proof links, blockers, progression decision, and reopened downstream scope. Stop after the selected subbundle closes or is honestly Blocked.
```
