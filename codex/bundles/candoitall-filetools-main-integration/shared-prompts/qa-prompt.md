# QA Prompt

```text
Independently gate the selected subbundle from current repositories and its declared proof tier.

Verify ownership, prerequisites, exact source anchors, dependency direction, package provenance, typed failure behavior, testability, partial-class policy, and progression/reopen rules. For Storage/providers verify bounds, capability honesty, freshness, cancellation, and safe errors. For effects verify current re-resolution/authorization, actor/runtime/operation/revision handles, endpoint policy, save conflict, and no unsigned/path fallback. For cache verify literal Disabled behavior, isolation, revision-after-success, and distributed fail-closed. For UI use the real production adapter in a managed browser at 1900x1200 and 1440x900; inspect DOM, scroll owner, open overlays, clipping/layering, state transitions, console/network, and screenshots.

Reject compile-only, count-only, fixture-only, screenshot-only, stale transcript, or intention-based proof. Confirm direct tests do not construct the old large owner. Run CodeAnalytics dependency/cycle evidence when references/architecture changed and Components MCP evidence when UI structure changed.

Return Pass, Fail, or Blocked with exact evidence, repairs, downstream impact, and owners to reopen. Update the execution report and raw-note closure only from verified evidence.
```
