# Structured Input

## Primary user goals

- Verify what Codex actually fixed and what remains insufficient.
- Check whether the CanDoItAll bundle workflow skill and validator are strong enough.
- Prepare a follow-up bundle that forces Codex to finish the missing behavior rather than passing with shallow reports.
- Keep economic memory-management models out of scope for now.

## Scope boundaries

- In scope: cognitive memory clustering, dreaming, professor/curator learning, assimilation/fading, recall synthesis, reference lineage, proof gates, and maintainability refactors.
- Out of scope: economic memory governance, market-pricing of attention, token lending, and other later governance layers.

## Key expectation

The system must behave like a student working with a professor: it captures the professor's correction, compares it with existing knowledge, uses it as temporary anchor evidence, gradually integrates it into derived memories and clusters, proves independent mastery, then fades the original professor wording only after the knowledge is actually internalized.
