## Invariant SB015-INV-001
- Invariant ID: `SB015-INV-001`
- Source raw note: Preserve pre-execution and start-transition behavior while continuing the Process Core contract candidate work; do not create Process Core or production driver APIs.
- Expected behavior: Database requirement blocking keeps the same status target and transition request shape, missing-upstream materialization keeps the same missing/no-op/fingerprint/rerun directive behavior, start-transition requests stay unchanged, and failed start transitions still reload the claimed candidate.
