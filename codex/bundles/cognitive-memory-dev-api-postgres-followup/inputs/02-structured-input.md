# Structured Input

## Primary Goal

Make Cognitive Memory testable and controllable through a developer API, then prove basic behavior on a fresh PostgreSQL database using detailed sample project-structure source data.

## Non-Goals

- Do not finish all remaining `cognitive-memory-architecture-v2` phases in this follow-up.
- Do not create direct DB seed scripts as the primary data path.
- Do not use SQLite for new behavior smoke validation.
- Do not hide missing semantic/RAG providers behind silent fallbacks.

## Required Test Data

The sample data must cover:

- Development of an offline-capable app.
- Business plan for a new SaaS.
- Docker-based development/deployment analysis.
- Non-programming economic analysis.
- Additional non-programming operational/community topics.

The data lives in `sample-source-data/` as markdown documents, mermaid mindmaps, and an API-load descriptor.
