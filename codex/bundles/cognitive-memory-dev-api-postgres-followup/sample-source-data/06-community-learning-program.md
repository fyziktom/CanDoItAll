# Community Learning Program

This program design supports adult digital literacy, job readiness, and local mentorship. The learners may have smartphones but limited laptop access, inconsistent internet, and low confidence from prior school experiences.

The curriculum is a twelve-week arc: device basics, email, online forms, document editing, spreadsheets for household budgets, job applications, video calls, and online safety. Each session ends with a practical artifact so progress is visible.

The partner model uses the library for space and devices, the workforce board for job pathways, employers for mock workplace tasks, and community groups for outreach. Mentors support practice labs but need boundaries so they do not become informal case managers.

Attendance barriers may dominate curriculum quality. The design includes flexible lab hours, loaner devices, child-friendly waiting space, bilingual support, transportation support, and a clear escalation path for social-service needs.
