# Clinic Operations Redesign

This non-software operations redesign targets a small outpatient clinic with long waits and unreliable follow-up. The constraint is important: no additional headcount and limited system changes.

The current intake process mixes predictable pre-visit work with arrival exceptions. The redesign moves insurance updates, forms, and routine symptom collection to pre-visit outreach, then reserves front-desk attention for exceptions. Rooming gets a standardized checklist for vitals, medication review, language support, and red-flag escalation.

Follow-up reliability is the largest safety risk. Labs, referrals, prescription questions, and patient portal messages need one visible queue with owner, due date, blocker, and contact status. Shared invisible ownership is explicitly rejected.

The two-week pilot covers one provider team, daily huddle review, role-specific job aids, and measures for median wait, ninety-fifth percentile wait, queue age, overtime, and reopened patient contacts.
