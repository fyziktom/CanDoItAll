# Review Prompt

Review the implementation as a senior C# architect.

Reject the implementation if:

- it creates Process Core or driver API;
- it removes artifact satisfaction paths;
- it changes auto-satisfaction ordering;
- response text can satisfy deliverables too broadly;
- provider-native browser evidence can satisfy without actual current output;
- shallow managed artifact paths are accepted;
- external-target alias checks are weakened;
- helpers hide file/DB/storage/transition side effects;
- tests are compile-only;
- small/medium/mobile proof artifacts appear.
