# Scope Inventory

## In Scope

- Process template JSON and markdown sidecars under `Templates/Processes`.
- Default process warmup list in `ProcessCatalogWarmupService`.
- Process template governance and subprocess integration tests.
- Agent instructions only if needed to clarify process-run screenshot/writeback targets.
- Bundle proof and execution report updates.

## Out Of Scope

- JavaScript delivery templates.
- Database migrations.
- Runtime process execution.
- Runtime branching engine changes.
- Product app generation.

## Expected New Templates

- `dotnet-architecture-design-review`
- `dotnet-runtime-command-writeback`
- `dotnet-ui-screenshot-writeback`
