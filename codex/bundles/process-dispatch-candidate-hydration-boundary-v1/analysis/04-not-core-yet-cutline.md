# Not Core Yet Cutline

Do not create Process Core in this bundle.

Why:

- Candidate hydration still directly depends on EF entity shape and module services.
- Technical-agent binding and project-structure access preparation remain side-effectful and product-specific.
- Artifact-input prompt shaping and branch outcome routing are still private dispatcher semantics.
- Driver vocabulary is still emerging through evidence/readiness maps.

Allowed now:

- Module-local candidate query and hydration helpers.
- Module-local snapshots that do not become public contracts.
- Documentation-only driver readiness maps.
- Architecture tests that prevent hidden Core/driver/API drift.

Not allowed now:

- `CanDoItAll.Processes.Core` project.
- `IProcessDriverPack`, `IProcessHelperDriver`, driver registry, or production driver package.
- Public promotion of private dispatcher types.
- Moving side effects into helpers named as pure.
