# Driver Readiness Candidate Map

Documentation-only. No production driver API in this bundle.

| Candidate fact | Future driver relevance | Current owner after this bundle |
| --- | --- | --- |
| Project id / project-structure context | Determines which project helper/driver may inspect context. | Candidate hydration snapshot / technical-agent binding coordinator. |
| Step kind and route kind | Distinguishes subprocess, workflow, direct-agent, manager recovery. | Candidate route snapshot / assembler. |
| Expected artifacts | Defines evidence contract that future helper drivers may satisfy. | Candidate hydration snapshot. |
| Artifact inputs | Defines upstream artifact dependencies and read-only input material. | Artifact input assembler. |
| Technical agent id and binding status | Determines executor availability and tool profile. | Technical-agent binding coordinator. |
| Required browser/build/test evidence | Later maps to domain helper drivers. | Existing validation/tool rules; documentation only here. |
| Manual recovery directive | Later may guide recovery helper driver. | Manual recovery directive query helper. |

Do not implement any driver from this map in this bundle.
