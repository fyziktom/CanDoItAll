# Not Process Core Yet

Do not start Process Core extraction in this initiative.

The current local boundaries are improving, but several module-local areas remain unstable:

- implementation proof and evidence intent;
- dotnet/js stack heuristics;
- concrete product path classification;
- receipt sequence proof;
- carried proof between attempts;
- recovery retry reason generation;
- runnable-host proof.

These are exactly the seams that future process helper drivers will need. They should be clarified first as local module helpers, then later promoted to contracts/core only when the vocabulary is stable and there are multiple consumers.

## Safe current goal

Create stable **module-local evidence-intent helper boundaries**.

## Unsafe current goal

Create production `IProcessDriverPack`, `CanDoItAll.Processes.Core`, or public process driver contracts.
