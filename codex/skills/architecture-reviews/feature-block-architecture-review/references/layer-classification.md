# Layer classification guide

## Domain Core
Owns canonical truth and core invariants.

## Policy / Authorization
Owns permissions, scopes, approval logic, and actor capabilities.

## Application Workflow
Coordinates use cases, orchestration, command handling, or task flows.

## Projection / View / Read Model
Derived representation for display, reporting, planning, search, or summaries.

## Integration Adapter / DTO
Shapes data for external systems, APIs, files, MCP tools, import/export, or provider-specific communication.

## UI State / View Layer
Temporary state required for forms, components, selections, layout, expand/collapse, or client-side interactions.

## Runtime / Dev Tooling
Watch helpers, diagnostics, log filtering, local tooling, operational monitors, and temporary execution support.
