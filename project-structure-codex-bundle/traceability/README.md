# Traceability assets

This folder contains machine-readable support files for the bundle.

- `feature_traceability.csv` — preserved features, source refs, current tests, and required validation.
- `method_inventory.csv` — method inventory across ProjectStructure, shared canvas components, adapters, and service layer.
- `existing_test_inventory.csv` — existing component and browser tests relevant to this refactor.
- `runtime_files.csv` — key runtime and validation files with responsibilities.
- `hotspots.csv` — prioritized performance findings.
- `subbundle_manifest.json` — structured task manifest.
