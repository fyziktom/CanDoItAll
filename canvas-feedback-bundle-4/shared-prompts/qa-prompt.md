# QA Prompt

Validate the selected-node inspector against the feedback screenshots and bundle requirements.

- repeated title or label content is gone from the primary card
- Progress, Priority, and Marker read as one deliberate row
- Artifact, Kind, Location, and typed details live behind an advanced reveal instead of dominating the panel
- action buttons have clearer affordance, consistent sizing, icons, and Delete last
- Edit opens a prefilled typed modal for supported nodes and saves through the explicit update path
- previews, runtime launch actions, transcript actions, and create-next-to-source still behave as before
