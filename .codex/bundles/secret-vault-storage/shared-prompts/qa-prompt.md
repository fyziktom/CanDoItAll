# QA Prompt

Validate the implemented subbundle against the bundle acceptance criteria, proof requirements, and raw input closure table.

- Search for new raw secret persistence in JSON/settings/log output paths.
- Confirm unsupported providers throw predictable `NotSupportedException` or equivalent explicit failures.
- Confirm runtime code resolves values only for selected references and immediate actions.
- For UI proof, open the relevant dialog/control and check readability, clipping, layering, copy affordances, and timed reveal auto-hide.
- Verify docs explain DPAPI Windows behavior, non-Windows provider state, and safe workflow/agent/project references.
