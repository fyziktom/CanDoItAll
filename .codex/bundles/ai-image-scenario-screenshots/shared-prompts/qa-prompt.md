# QA Prompt

Review the active subbundle as a senior CanDoItAll process and Blazor/.NET reviewer.

Check these questions before allowing progression:

- Did the implementation keep process core generic?
- Are provider, agent, process, and project-structure changes strongly typed where the codebase supports it?
- Are screenshots or generated layouts stored as image/file asset nodes, not only mentioned in notes?
- Did Playwright MCP capture real browser proof for the running app?
- Did the execution report record route/window, viewport, actions, assertions, screenshots, and result?
- Did API writes have readback proof from the specific affected project, process, agent, provider, or asset?
- Are OpenAI credential or model gaps explicit blockers instead of silent fallbacks?
