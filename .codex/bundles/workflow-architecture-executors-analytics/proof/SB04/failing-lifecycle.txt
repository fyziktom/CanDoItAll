Failing-first lifecycle gate

The corrected 11-test runtime lifecycle gate was executed in a temporary isolated test project before production implementation. The temporary project was removed after recording the gate.

Result: 0 passed, 11 failed, duration 355 ms.

Observed failures proved:
- no typed external-response or cancellation outcome on the legacy methods;
- inactive cancellation fabricated Cancelled;
- active cancellation could not find the run before backend completion;
- unsupported in-process response fabricated Completed;
- run/Started persistence failures did not prevent backend invocation;
- Running was not queryable while the backend was blocked;
- incremental progress was absent after backend failure;
- TimeProvider was not injectable.

The final test contract intentionally preserves legacy method signatures for caller compatibility and verifies the typed `RequestCancellationAsync` and `SubmitExternalResponseAsync` methods instead.
