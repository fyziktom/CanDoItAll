# Implementation Prompt

Use this prompt when executing the bundle:

```text
Implement the current subbundle only. Re-read the root README, phase plan, traceability, and selected subbundle README first. Validate prerequisites, make the smallest correct change, run the required proof, update the execution report and raw-note closure rows, and stop if the progression gate cannot pass honestly. Preserve the package isolation boundary: after the move, the main repo must not project-reference moved component projects.
```
