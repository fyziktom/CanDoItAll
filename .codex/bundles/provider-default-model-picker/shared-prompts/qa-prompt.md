# QA Prompt

Validate the active subbundle against the raw request, not only the code diff. Check that provider default is represented by empty agent model, provider suggested models render in the dropdown, override text remains possible, and provider changes do not keep stale model values. For UI proof, inspect the Runtime tab at a desktop viewport and check field labels, dropdown width, checkbox clarity, and override text field visibility. Record test commands, screenshots or browser blockers, gate results, and raw-note closure.
