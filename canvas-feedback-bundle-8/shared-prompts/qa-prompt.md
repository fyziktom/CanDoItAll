# QA Prompt

Validate the completed feedback8 subbundle against its acceptance checklist.

Required QA behavior:

- Re-run the listed build and test commands that cover the touched scope.
- Re-open the real app route in Playwright MCP.
- Perform every browser action listed in the subbundle Browser Validation Logging section.
- Capture or verify the required screenshots.
- Update the execution report with pass or fail status, proof paths, and any residual gaps.
