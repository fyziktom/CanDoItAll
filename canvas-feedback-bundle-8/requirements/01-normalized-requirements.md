# Normalized Requirements

| Requirement | Description | Source |
| --- | --- | --- |
| `R001` | The project-structure toolbox group headers must be directly clickable in the default desktop layout with no overlapping floating window intercepting pointer input. | `N001`, `N003` |
| `R002` | Toolbox groups must present as a real accordion while preserving the current search-driven expansion behavior. | `N002`, `N003` |
| `R003` | Opening a toolbox group must visibly reveal its child items and keep those items usable for creating nodes on the canvas. | `N004` |
| `R004` | Text and badge contrast must remain readable on both light and dark surfaces used by the page. | `N005` |
| `R005` | The selection panel must be pruned by node type so it shows only necessary information. | `N006` |
| `R006` | When guidance still matters after pruning, it must move behind a small contextual help affordance with tooltip behavior instead of permanent repeated prose. | `N006` |
| `R007` | File-node selection panels must not repeat subtype information in both text facts and badges. | `N007` |
| `R008` | File-type badges must use semantic colors by file type, such as green for Excel and red for PDF, with readable text contrast. | `N007`, `N005` |
