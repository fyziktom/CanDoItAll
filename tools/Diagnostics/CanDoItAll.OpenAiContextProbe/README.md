# CanDoItAll.OpenAiContextProbe

Runs a focused diagnostic probe for OpenAI context behavior through the application MAF
adapter and emits a bounded report for developer investigation.

Provide required credentials through supported secret configuration. Do not commit probe
output or provider payloads.

```powershell
dotnet run --project .\tools\Diagnostics\CanDoItAll.OpenAiContextProbe\CanDoItAll.OpenAiContextProbe.csproj
```
