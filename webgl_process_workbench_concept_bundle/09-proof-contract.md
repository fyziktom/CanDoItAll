# Proof contract

The concept is not considered proven by screenshots alone.

## Required proof layers

- build proof,
- focused component/integration proof for adapters and sandbox state,
- Playwright proof for semantic WebGL automation,
- browser screenshots for representative templates and viewports,
- final review notes that answer readability questions explicitly.

## Representative scenarios

- simple template,
- medium template,
- dense template,
- node move,
- connection mutation,
- screenshot export.

## Mandatory honesty rule

If the concept still has readability or automation failures, the execution report must state them explicitly. The bundle may conclude that the concept is not yet ready for a future pilot.
