# Scope inventory

## In scope

- prepared execution bundle and workbook,
- new universal WebGL library concept,
- new dedicated WebGL sandbox project,
- template-backed center-lane 3D scene projection,
- sandbox-only authoring interactions,
- semantic automation bridge,
- screenshot + semantic proof strategy,
- corrective playbooks and architecture review gates.

## Out of scope

- replacing the production `ProcessWorkspace`,
- production persistence for WebGL sandbox edits,
- a final product decision that WebGL must replace the existing 2D editor,
- deep performance tuning beyond deterministic concept-proof needs,
- mobile-first productization outside screenshot review.

## Concept success definition

The concept succeeds if it proves:

- a universal library shape is viable,
- dense scenes can be explored meaningfully in guided 3D,
- move/connect authoring is understandable,
- proof is automatable.
