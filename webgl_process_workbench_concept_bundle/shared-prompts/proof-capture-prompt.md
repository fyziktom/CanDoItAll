# Proof capture prompt

```text
Capture proof only for the selected subbundle.

Always record:
- exact route,
- viewport,
- template key,
- camera/view preset,
- semantic action performed,
- screenshot or export artifact path,
- pass/fail note,
- any inconsistency between screenshot and semantic snapshot.

Do not treat screenshots as sufficient proof for move/connect state changes without semantic assertions.
```
