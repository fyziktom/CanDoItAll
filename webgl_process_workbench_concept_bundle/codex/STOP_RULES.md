# Stop rules

- Stop immediately if the universal library starts to depend on `CanDoItAll.Modules.Processes`.
- Stop immediately if high-frequency rendering or hit-testing work migrates into Blazor per-frame logic.
- Stop immediately if the scene drifts from guided center-lane 3D into an uncontrolled free-camera UX without an explicit gate decision.
- Stop immediately if sandbox work starts to mutate persistent process data without a separately approved requirement.
- Stop immediately if Gate A or Gate B cannot be answered from fresh proof.
- Stop immediately if semantic automation remains impossible and the proof degrades to screenshots alone.
- Stop immediately if the DOM mirror becomes too weak for Playwright MCP to identify nodes, ports, edges, and interaction state.
- When a stop rule fires, execute the mapped corrective playbook, refresh proof, and rerun the blocked gate before anything else.
