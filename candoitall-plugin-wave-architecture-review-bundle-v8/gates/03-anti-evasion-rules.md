## Anti-evasion rules

Codex must not count any of the following as closure:

- leaving a forbidden symbol in place but “not using it much anymore”
- wrapping a switch/enum in another helper instead of moving the rule into the registry/manifest
- keeping dual truth and only adding comments/tests around it
- introducing a plugin key while still forcing the active editor flow through legacy enums
- adding compensation logic for side effects instead of a durable intent boundary
- claiming runtime success without real build/test/run evidence
