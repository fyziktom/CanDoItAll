## Normalized requirements

1. **Node remains central.**  
   The target architecture must keep node as a genuine universal carrier for the project-operating-system model. It must not become a disposable UI view.

2. **Mindmap semantics stay canonical.**  
   XY coordinates, hierarchy, markers, core text, subtype, schedule, and status must be treated as canonical project semantics.

3. **Ownership must be explicit.**  
   For every concept, it must be clear whether the source of truth is:
   - node core,
   - binding/facet/reference record,
   - projection contributor / assembly,
   - plugin manifest,
   - UI state,
   - or background integration workflow.

4. **Plugin wave must be first-class.**  
   Email, LinkedIn, and custom API integrations should be pluggable without expanding core enums or switch-based editor pages.

5. **Future side effects must be durable.**  
   External write-side integrations must not rely only on inline calls and rollback/compensation.
