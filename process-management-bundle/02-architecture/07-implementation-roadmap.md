# Implementation roadmap

## Wave 0
- freeze ADRs and review checklists
- scaffold `CanDoItAll.Modules.Processes`
- reserve migrations and test shells

## Wave 1
- module foundation
- process DSL and versioning
- actor bindings
- role/agent templates
- step contracts
- ownership / customer / criticality / interface metadata
- canvas authoring core

## Wave 2
- transitions and handoffs
- approvals and governance gates
- runtime state machine
- journal and replay
- variants, exceptions, input quality, and decision rights
- process-native work briefs, baton handoffs, and governed triage routing
- Mermaid / JSON interop

## Wave 3
- project/workbench projections and typed context links
- activity / automation / validation / TestLab hooks
- future AgentFramework seam
- live process execution canvas overlays and baton visibility
- AgentFramework convergence rules for context, rights, and shared registries
- change governance, prioritization, literacy, and management adoption

## Wave 4
- outcome telemetry and capacity insights
- improvement backlog / training opportunity loop
- conformance and paper-versus-reality review
- production-scale hardening

## Delivery stance

This roadmap keeps the user's intended order:

1. ship process management first
2. make the process the visible and governable collaboration graph
3. only then bridge future AI execution through that process model
