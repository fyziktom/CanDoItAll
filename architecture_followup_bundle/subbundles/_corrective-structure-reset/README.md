# Corrective playbook — structure reset

Invoke this when late-stage structural cleanup re-centralizes logic or destabilizes hardened invariants.

## Trigger examples

- logic merely moved between partial classes;
- new state duplication appears between workspace and service seams;
- component/service follow-up reopens already-closed invariant bugs.

## Mandatory repair moves

- restore thin seams and explicit ownership;
- rerun component and targeted integration proof before final closure.
