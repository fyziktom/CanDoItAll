## Navigation advice

- When implementing a **shared graph component**, start with `workbench_contracts`, `workbench_component`, and `workbench_js`.
- When implementing a **Project Structure adapter**, start with `project_structure_page`, `project_structure_catalog`, and `project_workbench_models`.
- When implementing a **Prompt Factory adapter**, start with `prompt_factory_page`, `prompt_factory_catalog_page`, `prompt_factory_history`, `prompt_factory_catalog`, and `prompt_factory_service`.
- When implementing a **calendar migration**, start with `calendar_component`, `calendar_interop`, `project_calendar_page`, and `legacy_project_calendar_component`.
- When validating whether a feature is already partially present, always inspect `workbench_js` before deciding to build a fresh subsystem.
