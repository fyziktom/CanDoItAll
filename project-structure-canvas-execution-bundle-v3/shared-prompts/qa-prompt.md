# QA Prompt

Validate the shipped bundle against browser truth and current source reality.

- Audit the active runtime source for canvas stage ownership, export composition, state persistence, move flow, and shared asset includes.
- Run asset verification plus the full component and Playwright packs.
- Compare the execution report, raw note closure, and bundle summary against the current repository state.
- Reopen the bundle if any report claim is contradicted by source, tests, or browser artifacts.
