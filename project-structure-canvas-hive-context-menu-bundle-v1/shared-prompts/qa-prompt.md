# QA Prompt

Validate the current subbundle on the project-structure structure-canvas route. Prove the intended behavior with exact assertions, not screenshot-only reasoning. For UI phases, open the context menu in browser, confirm first-ring ordering, review density and spacing, verify no clipping or overlap, and capture large-screen plus narrower-width screenshots. Reopen the subbundle if the menu still feels loose, the hive does not read clearly, or keyboard and submenu behavior regresses.
