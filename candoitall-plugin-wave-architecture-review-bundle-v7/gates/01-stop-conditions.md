# Stop conditions

Stop the connector/plugin wave immediately if any of the following are still true:

- SyncGraph-like projection persistence still exists in Workbench canonical storage.
- The same node carrier still owns artifact/media/storage/provider/resource binding concerns.
- Reclassification still mutates node kind in place without writing history.
- Editable hierarchy still dual-writes containment into generic link rows.
- New connectors still require enum expansion.
- Hard-gate tests or the hard-gate script still fail.
