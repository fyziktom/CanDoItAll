# Checklist release readiness

- [ ] Verze balíčku je nastavena.
- [ ] Manifest SHA256 je aktualizovaný.
- [ ] Nejsou otevřené P0/P1 blokery.
- [ ] Known risks jsou explicitně zapsané.
- [ ] Security review je dokončená.
- [ ] Observability a redaction jsou zkontrolované.
- [ ] Example configy jsou konzistentní se skutečným kódem.
- [ ] Example compose soubory byly aspoň jednou validované.
- [ ] Tool contracts jsou sladěné s implementací.
- [ ] CI pipeline build/test/pack prochází.
- [ ] E2E staging deploy proběhl úspěšně.
- [ ] Rollback scénář proběhl úspěšně.
- [ ] Dokumentace obsahuje onboarding pro Codex.
