# Capability authoring scenarios

Open `/authoring/NewMcp`, `/authoring/NewSkill` or `/authoring/NewTool` for the real
wizard. The selector also exposes every supported details mode, built-in restrictions,
malformed/unavailable configuration, load failure, rejected/conflicting/unknown saves,
held operations and large content. Stored definitions are separate immutable values.
Open dialog and Second editor use the real shared modal and independent draft lifetimes.

Setup responses here are deterministic simulations. Native process, HTTP and MCP
execution is proved separately through the application owners. The host references
only the rendering leaf, uses the production stylesheet and preserves publish assets.
Generate the application's Tailwind stylesheet before publishing; a missing file fails
the build. Browser validation uses 1920×1080 at scale 1.

See [Testing](../../../docs/testing.md#capability-authoring-ca1) for commands and the
[architecture record](../../../docs/architecture/agent-authoring-ui-ca1.md) for closure.
