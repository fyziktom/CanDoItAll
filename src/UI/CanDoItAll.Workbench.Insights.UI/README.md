# Workbench Insights UI

The actual Manager Summary, Activity, Selection Panel, advanced node details,
Object Index, Signals and Canvas Health renderers used by production Workbench and
the independent Insights sandbox. Their scoped CSS belongs here. Charts, floating
windows, TreeView, dialogs, fonts and browser runtimes belong to Components.

Each report view owns its draft, accepted snapshot and pending operations. Native
adapters supply captured queries and accepted presentation values. Support intents
carry the original project/profile/lifetime, view, selection revision, receiver and
targets. Native owners enforce admission and reconcile committed results.

Task editing, file/Mermaid content, assignments, runtime execution, confirmations
and the main Structure canvas remain native integrations. This library has no
product implementation dependency or feature-owned JavaScript.

Run the [independent sandbox](../../Sandboxes/CanDoItAll.Workbench.Insights.UiSandbox/README.md)
for Fast/Parity development. See the [WB2 architecture and proof record](../../../docs/architecture/workbench-insights-wb2.md)
and [UI component seams](../../../docs/architecture/ui-component-seams.md).
