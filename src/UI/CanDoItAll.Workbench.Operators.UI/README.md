# Workbench Operators UI

Independent Blazor presentation for participant and meeting authoring. `PartyEditor` owns
rendering and bounded callback admission; its typed state carries one opening's draft,
choices and native outcome facts. The Workbench host supplies effects and authority.

This leaf references only neutral Components and RecordBrowsing. It does not read project,
directory, vault or process stores. Build with `dotnet build` on this project. The independent
Operators UI tests and Operators sandbox consume the same production renderers.

See [the WB5 architecture record](../../../docs/architecture/workbench-operators-wb5.md)
for native ownership, checkpoint evidence and remaining families.
