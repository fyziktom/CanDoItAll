# Storage selection contracts

Immutable catalog display metadata and a contextual read-only source for the Storage
selection field/dialog. The context stamp detects retired reads; it grants no authority.
No Infrastructure records, credentials, configuration, drivers or persistence APIs cross
this boundary. The Workspace adapter retains the existing catalog bootstrap/read owner.
See the [boundary record](../../../docs/architecture/workspace-storage-selection-ui-boundary.md).
