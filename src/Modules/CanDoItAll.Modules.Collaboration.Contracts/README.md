# Collaboration contracts

Implementation-free Collaboration requests, workspace snapshots, annotated editor models
and enums. Existing namespaces, member shapes and string-persisted enum names are retained.
There are no EF records, UI framework dependencies, services or database registrations here.

```powershell
dotnet build src/Modules/CanDoItAll.Modules.Collaboration.Contracts/CanDoItAll.Modules.Collaboration.Contracts.csproj --configuration Release /m:1
```

See the [boundary record](../../../docs/architecture/collaboration-ui-boundary.md).
