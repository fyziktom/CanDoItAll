# CanDoItAll.Modules.Memory

Provides Memory provider configuration, setup diagnostics, operation views, navigation,
and application-facing services.

The module orchestrates `src/Memory` through typed contracts. Provider transports,
operation semantics, and persistence remain in their owning projects.

```powershell
dotnet build .\src\Modules\CanDoItAll.Modules.Memory\CanDoItAll.Modules.Memory.csproj
```
