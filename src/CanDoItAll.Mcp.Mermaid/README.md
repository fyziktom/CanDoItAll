# CanDoItAll.Mcp.Mermaid

Static Mermaid syntax guidance MCP server for CanDoItAll agents.

The catalog records Mermaid 11.14.0 authoring rules, examples, and graph-type-specific forbidden-symbol guidance. It is intentionally a knowledge server, not a replacement parser. Runtime rendering and parser diagnostics remain owned by the `CanDoItAll.Components.Mermaid` wrapper around the official Mermaid.js ESM bundle.
