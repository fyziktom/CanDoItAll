# CanDoItAll.Memory.Abstractions

Defines provider-neutral Memory capabilities, identifiers, operation envelopes, ledger
records, feedback, events, results, and extension-data contracts.

The project contains no transport, persistence, provider selection, or UI behavior.

```powershell
dotnet build .\src\Memory\CanDoItAll.Memory.Abstractions\CanDoItAll.Memory.Abstractions.csproj
```
