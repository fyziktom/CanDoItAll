# CanDoItAll.Memory.Http.Contracts

Defines the typed request and response payloads used by HTTP-backed Memory providers.

Transport execution, authentication headers, URI construction, response limits, and
mapping belong in `CanDoItAll.Memory.Http`.

dotnet build .\src\Memory\CanDoItAll.Memory.Http.Contracts\CanDoItAll.Memory.Http.Contracts.csproj
