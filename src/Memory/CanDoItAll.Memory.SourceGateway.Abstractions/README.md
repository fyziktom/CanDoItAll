# CanDoItAll.Memory.SourceGateway.Abstractions

Defines identifiers, paging cursors, hashing, security metadata, snapshots, and provider
contracts for importing bounded source content into Memory.

Source implementations must preserve deterministic paging, scope, and security metadata.

```powershell
dotnet build .\src\Memory\CanDoItAll.Memory.SourceGateway.Abstractions\CanDoItAll.Memory.SourceGateway.Abstractions.csproj
```
