# CanDoItAll.Processes.Templates

Loads, validates, scans, and materializes process template packs from
`Templates/Processes`.

Template definitions are repository-owned application inputs. Compatibility diagnostics
are typed results and do not create hidden runtime fallback behavior.

```powershell
dotnet build .\src\Processes\CanDoItAll.Processes.Templates\CanDoItAll.Processes.Templates.csproj
```
