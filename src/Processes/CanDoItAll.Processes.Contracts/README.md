# CanDoItAll.Processes.Contracts

Defines versioned process acceptance criteria, capability scopes, subprocess payloads,
workflow executor contracts, and cross-boundary operation names.

These contracts are stable transport/domain inputs and contain no runtime or persistence
implementation.
