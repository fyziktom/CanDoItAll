# CanDoItAll.Processes.Projections

Builds process read models for definitions, canvases, editors, execution observation,
history, and cost queries from canonical runtime records.

Projections are query models. Commands must use the application/runtime boundary rather
than mutating projection storage.

```powershell
dotnet build .\src\Processes\CanDoItAll.Processes.Projections\CanDoItAll.Processes.Projections.csproj
```
