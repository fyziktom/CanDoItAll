# CanDoItAll.Processes.Abstractions

Defines strongly typed process, definition, instance, run, step, and related identifiers.

Use these identities at module, API, persistence, driver, and runtime boundaries instead
of raw strings.

```powershell
dotnet build .\src\Processes\CanDoItAll.Processes.Abstractions\CanDoItAll.Processes.Abstractions.csproj
```
