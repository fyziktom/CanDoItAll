# CanDoItAll.Processes.Drivers.Abstractions

Defines process driver catalogs, descriptors, packages, strategies, execution adapters,
tokens, diagnostics, and result contracts.

Drivers translate a process step into bounded execution behavior; the process runtime
retains state-transition authority.
