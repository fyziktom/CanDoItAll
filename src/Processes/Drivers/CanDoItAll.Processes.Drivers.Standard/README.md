# CanDoItAll.Processes.Drivers.Standard

Provides built-in process adapter descriptors, driver package construction, and standard
execution strategy factories.

The project implements driver contracts only and has no process persistence or UI
responsibility.

```powershell
dotnet build .\src\Processes\Drivers\CanDoItAll.Processes.Drivers.Standard\CanDoItAll.Processes.Drivers.Standard.csproj
```
