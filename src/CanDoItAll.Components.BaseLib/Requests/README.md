# BaseLib Requests

`CanDoItAll.Components.BaseLib` is owned from the CanDoItAll repo.

Other repos, including Zyphonote, must not patch this shared library directly from their side. File a request in this folder and implement the shared-library change from CanDoItAll.

Preview, demo, tuning, and fake-data assets do not belong in `BaseLib`. Put those in `CanDoItAll.Components.Sandbox`.
