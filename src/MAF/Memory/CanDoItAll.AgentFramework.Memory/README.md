# CanDoItAll.AgentFramework.Memory

Connects the Memory application boundary to agent context construction, provider routing,
runtime tools, result shaping, and workflow executors.

Memory provider protocols and persistence remain in `src/Memory`; agent execution policy
and workspace orchestration remain in AgentFramework Core.

```powershell
dotnet build .\src\MAF\Memory\CanDoItAll.AgentFramework.Memory\CanDoItAll.AgentFramework.Memory.csproj
```
