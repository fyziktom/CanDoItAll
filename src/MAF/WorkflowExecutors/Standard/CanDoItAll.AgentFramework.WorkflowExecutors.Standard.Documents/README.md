# CanDoItAll.AgentFramework.WorkflowExecutors.Standard.Documents

Implements document-to-Markdown and spreadsheet workflow executors using the document
tool boundary.

Input files, output artifacts, size limits, and format diagnostics are validated before
the executor returns a typed result.

```powershell
dotnet build .\src\MAF\WorkflowExecutors\Standard\CanDoItAll.AgentFramework.WorkflowExecutors.Standard.Documents\CanDoItAll.AgentFramework.WorkflowExecutors.Standard.Documents.csproj
```
