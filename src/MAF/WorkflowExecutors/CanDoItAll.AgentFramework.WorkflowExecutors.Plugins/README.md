# CanDoItAll.AgentFramework.WorkflowExecutors.Plugins

Adapts activated plugin packages to workflow executor contracts, including grant
evaluation, OAuth access, source mapping, and runtime registration.

Plugin executors run only through an active package and validated capability/OAuth
boundary.

```powershell
dotnet build .\src\MAF\WorkflowExecutors\CanDoItAll.AgentFramework.WorkflowExecutors.Plugins\CanDoItAll.AgentFramework.WorkflowExecutors.Plugins.csproj
```
