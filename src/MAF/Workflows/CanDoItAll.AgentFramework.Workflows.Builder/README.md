# CanDoItAll.AgentFramework.Workflows.Builder

Provides strongly typed builders for workflow definitions, nodes, ports, edges, and input
parameters, plus deterministic fixture construction.

Builders create the domain definition; validation and persistence remain in Workflow
Core.

```powershell
dotnet build .\src\MAF\Workflows\CanDoItAll.AgentFramework.Workflows.Builder\CanDoItAll.AgentFramework.Workflows.Builder.csproj
```
