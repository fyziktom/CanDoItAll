# CanDoItAll.AgentFramework.Workflows.Abstractions

Defines workflow catalog, launch, dashboard, analytics, runtime, failure, and query
contracts shared by UI, API, runtime, and adapters.

The contracts do not select persistence or Microsoft Agent Framework implementations.
