# Neutral Workflow definition rules

Pure routing syntax/value validation and execution-policy limits shared by the
native compiler/validator and the independent authoring UI. This project references
Models only. It contains no runtime execution, persistence, native owner or UI DI.
Routing evaluation and executor invocation remain in their existing runtime owners.

See [Workflow authoring WF1](../../../../docs/architecture/workflow-authoring-ui-wf1.md)
for the boundary, evaluated dependency graphs and validation status.
