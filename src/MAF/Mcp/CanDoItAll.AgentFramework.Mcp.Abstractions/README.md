# CanDoItAll.AgentFramework.Mcp.Abstractions

Defines provider-neutral MCP descriptors, transport settings, setup contracts, and tool
selection models used by the application runtime.

Developer-side MCP server implementations and launch configuration are outside this
repository.

```powershell
dotnet build .\src\MAF\Mcp\CanDoItAll.AgentFramework.Mcp.Abstractions\CanDoItAll.AgentFramework.Mcp.Abstractions.csproj
```
