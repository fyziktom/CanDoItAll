# CanDoItAll.AgentFramework.Tools.Abstractions

Defines provider-neutral tool descriptors and contracts used by AgentFramework setup and
execution.

Tool implementations, process launch, protocol handling, and UI belong in implementation
or owning module projects.

```powershell
dotnet build .\src\MAF\Tools\CanDoItAll.AgentFramework.Tools.Abstractions\CanDoItAll.AgentFramework.Tools.Abstractions.csproj
```
