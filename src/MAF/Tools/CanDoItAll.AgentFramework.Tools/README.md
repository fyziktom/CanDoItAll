# CanDoItAll.AgentFramework.Tools

Implements internal and external tool descriptors, setup validation, diagnostics, and
tool registration support.

Invocation remains governed by capability, approval, isolation, workspace, and secret
policies. Failures return bounded actionable diagnostics.
