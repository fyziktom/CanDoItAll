# CanDoItAll.AgentFramework.Tooling

Defines `IAgentRuntimeToolProvider` and the typed metadata used by modules to contribute
first-party runtime tools.

The provider contract describes purpose and operations; capability policy decides which
contributed tools are attached to an execution.

```powershell
dotnet build .\src\MAF\Tools\CanDoItAll.AgentFramework.Tooling\CanDoItAll.AgentFramework.Tooling.csproj
```
