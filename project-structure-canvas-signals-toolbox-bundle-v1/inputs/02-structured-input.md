# Structured Input

## User Intent

- Improve legibility of marker choices in the second-layer context menu.
- Add a selection-aware floating toolbox for node signals.
- Support additive markers on nodes instead of only one marker at a time.

## Non-Negotiables

- Keep the marker badge circle the same size.
- Expose the new toolbox from the top canvas toolbar.
- Make the toolbox act on the current selected node.

## Inspiration Constraint

- Use the XMind screenshot for grouped palette composition only, not for literal style copying.
