# Original Request

Implement a bundle-driven redesign of process template browsing and importing inside Process management.

Raw request summary:

- Replace `Seed development baseline` with `Templates`.
- Open a fullscreen modal.
- Left panel must be searchable and tabbed by template category.
- Categories must cover process templates, role templates, and artifact templates.
- Right panel must preview the selected template.
- Mermaid preview must use `MermaidJS.Blazor` and support pan and zoom.
- Markdown preview must use `Markdig`.
- Json preview must use `JsonViewer.Blazor`.
- A tree view must show the structure of the selected template definition.
- Users must be able to add a full process template to their process library.
- Users must be able to add just a role from a process template without importing the whole process.
- Users must be able to add role and artifact templates into their current process authoring workflow.
- The modal must stay open after import and a notification must appear above the modal.
- The work must be prepared and executed through the CanDoItAll bundle workflow, then fully validated and tested.
