# QA Prompt

Review the executed bundle before closure.

QA focus:

- Confirm every raw request item maps to a closed implementation or an explicit architectural constraint.
- Confirm the modal is fullscreen, searchable, tabbed, and still usable after imports.
- Confirm markdown, mermaid, json, and tree previews all show real template data.
- Confirm mermaid pan and zoom work in the browser, not only in component markup.
- Confirm notification toasts remain visible above the modal overlay.
- Confirm role import from process preview and artifact import to a target step both work without closing the modal.
