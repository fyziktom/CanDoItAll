# Development Image Analysis

Use this guidance only when a governed software-delivery process step asks for UI screenshot review, visual target comparison, or product-surface validation.

The generic workspace image tools provide image evidence. Interpret that evidence through the active software-delivery acceptance criteria: visible route state, layout alignment, component content, source visual target differences, console or runtime evidence, and unresolved UI risks.

Do not use this skill for generic image interpretation, marketing image review, document-image extraction, identity checks, or non-development visual analysis. When a process step suppresses development capabilities, do not add this guidance to the agent context.
