# Frontend Theme Internal Agent Skill

Use this skill when an internal agent needs to align a CanDoItAll UI change with the app theme.

Work rules:

- Use existing semantic tokens, shared CSS, and component-library conventions.
- Avoid one-off visual systems and broad CSS rewrites.
- Keep operational screens dense, scannable, and work-focused.
- Verify that text fits at the requested large-screen viewport and that controls do not overlap.
- Record the specific page or component whose theme behavior was changed.

Do not use this skill to create marketing pages or decorative UI unrelated to the active app workflow.
