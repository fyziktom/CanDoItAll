# .NET Blazor SSR solution setup subprocess

**Key:** `dotnet-blazor-ssr-solution-setup`
**Criticality:** Standard
**Autonomy level:** Assisted

Atomic child process for creating a named .NET solution, Blazor SSR app, xUnit test project, project references, and first build proof.

## Steps
- Capture solution scaffold contract.
- Create solution and Blazor SSR app.
- Add xUnit test project and reference.
- Validate first build and test discovery.
- Hand off setup evidence.
