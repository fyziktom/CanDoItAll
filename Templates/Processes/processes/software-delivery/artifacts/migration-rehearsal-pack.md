# Migration rehearsal pack

**Key:** `migration-rehearsal-pack`  
**Scope:** local  
**Process:** software-delivery  
**Artifact kind:** Evidence  
**Owner role key:** `data-migration-owner`  
**Default trust requirement:** ReviewRequired  
**Default sensitivity level:** Restricted  
**Default retention days:** 730

## Summary
Evidence pack from rehearsal or dry-run execution of a risky schema or data migration.

## Allowed future usage
Reusable for release approval, rollback review, and post-release forensic analysis only for the covered migration path.

## Validation requirement
Must show rehearsal scope, dataset assumptions, timing, and rollback observations.
