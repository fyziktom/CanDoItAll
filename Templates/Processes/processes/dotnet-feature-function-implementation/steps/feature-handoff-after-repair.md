# Hand off repaired feature implementation

Produce a parent-ready handoff for a repaired and accepted feature.

Include:

- Original accepted feature scope.
- Initial implementation summary.
- Validation failure that triggered repair.
- Repair change summary.
- Recheck commands, exit codes, browser/runtime proof when applicable, and evidence refs.
- Residual risks and explicit parent recommendation.

Do not present unresolved repaired proof as accepted. If recheck selected `feature-repair-escalation`, this step must remain skipped.
