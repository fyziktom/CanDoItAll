# Prompt / ADR question framing

**Key:** `prompt-adr-question-framing`  
**Scope:** local  
**Process:** architecture-decision-governance  
**Audience role key:** `governance-facilitator`

## Summary
Prompt scaffold for rewriting fuzzy design debates into crisp decision questions.

## Required inputs
- current proposal
- drivers
- known options
- deadline

## Output schema
- decision question
- options
- decision deadline
- required participants
- decision consequences
