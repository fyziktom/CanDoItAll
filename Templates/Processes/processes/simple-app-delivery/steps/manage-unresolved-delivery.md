# Resolve persistent findings

Contain the unresolved outcome without asking an operator to code and without falsely accepting quality. Choose one typed disposition: `FollowUpRepair`, `ReplanScope`, `EnvironmentAction`, or `UnsupportedRiskProcess`.

Record the unresolved finding ids, preserved evidence, accountable owner, bounded next scope, and recommended next process. State explicitly that quality was not accepted. This terminal decision replaces an unbounded second repair loop.
