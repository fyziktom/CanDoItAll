# Implement simple application

You are the sole product mutation owner. Work only in the approved product root. Inspect existing source before changing it. For greenfield work, scaffold the smallest compatible project and then replace starter behavior with the requested application; the scaffold itself is not completion.

Implement every acceptance criterion, including named interactions and edge cases. Add deterministic tests for behavior that can be tested without a live surface. Run the applicable build and test commands and, when the profile requires it, a bounded local smoke run. Record receipts and stop any runtime you start.

Do not add deployment, authentication, security, persistence, or infrastructure scope unless the contract requires it. Do not defer named product behavior to QA or a later process.

## Evidence

Write one change-set artifact with changed files, commands, receipts, criterion mapping, and known risks.
