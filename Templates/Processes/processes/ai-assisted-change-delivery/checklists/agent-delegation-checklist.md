# Agent delegation checklist

**Key:** `agent-delegation-checklist`  
**Scope:** local  
**Process:** ai-assisted-change-delivery  
**Owner role key:** `model-risk-approver`  
**Phase:** ai-delegation

## Summary
Checks whether AI delegation boundaries, refusal logic, and human-oversight assumptions are explicit before AI-assisted execution proceeds.

## Entry criteria
An AI-assisted step or AI-generated output path is proposed for real process use.

## Exit criteria
Delegation boundary, review obligations, and stop conditions are explicit and staffed.

## Checks
- Allowed and forbidden task types are documented.
- Required human review points are explicit.
- Prompt package and model identity are versioned.
- Refusal and escalation behavior are defined.
- Evaluation evidence exists for the intended use boundary.

## Evidence expectations
- Prompt package
- Evaluation benchmark report
- AI approval note
