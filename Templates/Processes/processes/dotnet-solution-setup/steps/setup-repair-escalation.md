# Escalate unresolved setup repair

Record unresolved repaired setup findings for the parent process. This is a no-go packet, not accepted setup handoff.

Write the escalation packet to `artifacts/process-runs/<current-process-run-id>/steps/setup-repair-escalation.md` and include the initial failure, attempted repair, repaired validation result, failing commands, no-go rationale, and required next scope.
