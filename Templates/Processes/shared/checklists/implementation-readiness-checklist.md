# Implementation readiness checklist

**Key:** `implementation-readiness-checklist`  
**Scope:** shared  
**Process:** shared  
**Owner role key:** `delivery-manager`  
**Phase:** implementation

## Summary
Execution-readiness gate ensuring work is staffed, sequenced, and evidence-aware before heavy implementation starts.

## Entry criteria
Scope and architecture direction exist and implementation is about to begin.

## Exit criteria
Implementation path is clear enough that delivery teams should not need to invent governance or acceptance semantics mid-flight.

## Checks
- Primary responsible role and fallback coverage are defined.
- Dependencies and prerequisite decisions are identified.
- Acceptance criteria and evidence expectations are available.
- Rollback or safe-stop thinking is present for risky change types.
- Environment, access, and tool prerequisites are understood.
- Escalation triggers are defined for predictable blockers.

## Evidence expectations
- Implementation plan.
- Role assignment view or equivalent staffing decision.
- Checklist sign-off or explicit exception note.
