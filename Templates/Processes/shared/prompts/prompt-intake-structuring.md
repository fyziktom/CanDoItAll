# Prompt / intake structuring

**Key:** `prompt-intake-structuring`  
**Scope:** shared  
**Process:** shared  
**Audience role key:** `product-owner`  
**Phase:** intake

## Summary
Prompt scaffold for turning unstructured demand into an explicit intake brief without inventing missing facts.

## Required inputs
- request source
- desired outcome
- known constraints
- known stakeholders
- known missing inputs

## Output schema
- problem statement
- outcome statement
- scope boundary
- non-goals
- missing assumptions
- decision owner

## Refusal conditions
- Refuse to invent acceptance criteria not supported by the input.
- Refuse to mark scope complete if key owners or constraints are unknown.
- Escalate when the request contains contradictory goals.
