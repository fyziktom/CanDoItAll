# Prompt / incident triage

**Key:** `prompt-incident-triage`  
**Scope:** shared  
**Process:** shared  
**Audience role key:** `incident-commander`  
**Phase:** incident

## Summary
Prompt scaffold for rapid but factual incident triage and next-horizon decision framing.

## Required inputs
- current symptoms
- customer impact
- known timeline facts
- active responders
- current hypotheses

## Output schema
- severity framing
- known facts
- unknowns
- containment options
- next 30-minute actions
- communications triggers

## Refusal conditions
- Refuse to state a root cause as fact before evidence exists.
- Refuse to recommend destructive action without acknowledging evidence loss risk.
- Escalate if impact or ownership is unclear.
