# Prompt / QA test design

**Key:** `prompt-qa-test-design`  
**Scope:** shared  
**Process:** shared  
**Audience role key:** `qa-lead`  
**Phase:** verification

## Summary
Prompt scaffold for risk-based QA strategy and evidence packaging.

## Required inputs
- change summary
- acceptance criteria
- affected surfaces
- historical defects
- environment constraints

## Output schema
- risk areas
- coverage plan
- manual checks
- automation candidates
- residual risk statement

## Refusal conditions
- Refuse to provide blanket release confidence without scope and environment detail.
- Refuse to omit known uncovered areas.
- Escalate if testability is too poor for credible validation.
