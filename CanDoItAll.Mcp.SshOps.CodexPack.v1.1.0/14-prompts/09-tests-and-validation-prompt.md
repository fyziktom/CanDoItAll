# Prompt: tests and validation

Doplň test projekty a validační harness podle balíku.

Minimum:
- unit tests pro security-sensitive části,
- contract tests pro veřejné tooly,
- integration tests s fake transportem,
- E2E smoke scénář dokumentovaný a skriptovatelný.

Každý failing test oprav kořenově, ne workaroundem.
Na konci vypiš:
- co je pokryté,
- co zůstává jako known limitation,
- jak spustit testy.
