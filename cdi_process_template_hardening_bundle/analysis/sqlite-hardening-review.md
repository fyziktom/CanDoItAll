## Senior-architect conclusion
SQLite is already known to be unforgiving when a feature relies on loosely coordinated writes, long lock windows, or hidden retry assumptions. The process module therefore needs explicit review of import, delete, seed, and transition write paths. The new bundle keeps this review mandatory instead of treating provider behavior as an implementation detail.
