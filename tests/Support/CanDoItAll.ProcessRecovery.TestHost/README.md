# Process cancellation restart fixture

This support executable runs only the registered cancellation recovery worker against an
existing, isolated parent-owned PostgreSQL profile and File workspace. It creates no
listener, schema, container or provider seed. The Integration project builds it in the
same standard configuration; the test records the exact assembly and process identities.

The three typed modes hold immediately before original child accounting, hold after its
owner commits but before the queue checkpoints, or resume normally. The holds decorate
the actual registered dispatcher and queue only in this executable. A 90-second process
lifetime bounds abandoned test work; the parent owns termination and cleanup. Standard
output contains bounded typed frames; diagnostics contain exception types and frames,
without configuration or exception messages. Connection credentials enter only through
the parent's private environment.

`ProcessCancellationRecoveryRestartTests` exercises both snapshot modes and both holds,
terminates the first OS process, and requires the next process to recover the original
action, retain receipts, charge original work once and finish the root. The ordinary
application and its databases are never valid fixtures for this executable.
