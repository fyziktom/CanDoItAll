# Workbench Insights renderer tests

Build the Insights.UI production project first, then this project. Discover and run
`FullyQualifiedName~CanDoItAll.Workbench.Insights.UI.Tests.Reporting` for the reporting
checkpoint (13 cases). Use the same configuration for both commands.

The controlled completions exercise cancellation, stale progress/error/finally,
confirmation, independent views, accepted report ranges and Activity opening/paging.
bUnit renders the actual controls and charts with neutral component services.
Native reporting arithmetic, project lifetime checks, Process cursors, file access
and mutation outcomes belong to the native owning suites and application journeys.
