# Production Recovery browser fixture

Task-owned PostgreSQL, roots and a real Web/Kestrel host exercise two interrupted
Workflow output continuations. The fixture substitutes only a controlled native commit
fault and observes driver dispatch. Actual recovery owners, file bytes, authorization,
managed credentials and original Workflow receipts remain real. Automatic Workflow
delivery is stopped while creating the interrupted fixture state.

Only safe IDs, content hashes and counters enter proof output. A short-lived token is
passed through the fixture's private root and removed after browser setup. The test
uses authenticated LongPolling and explicitly tests read-only grants. Disposal stops
the exact owned host and cleans its private database/root through test support.
This is deterministic production UI proof, not a live provider execution.
