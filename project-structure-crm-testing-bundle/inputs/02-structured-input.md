# Structured Input

## Inputs

- Reconstruct the delivered CRM/HR initiative as a project-structure plan instead of re-executing the original bundle.
- Use a new isolated SQLite profile stored under repo artifacts.
- Create one umbrella project and split detailed work into subprojects where it improves control and readability.
- Add AI-agent participants and connect ownership to tasks, especially inside the CRM/HR planning surface.
- Validate the visual result in the structure canvas with Playwright MCP screenshots.
- Record every discovered limitation or confusion as a finding, separated into MCP-specific and general findings.

## Output Expectations

- A local CanDoItAll project hierarchy visible in the app.
- A readable management plan that covers the source bundle end to end.
- Browser proof and screenshots of the resulting structure canvas.
- Findings files under `findings/mcpfindings` and `findings/generalfindings`.
- Bundle documentation synchronized with execution reality.
