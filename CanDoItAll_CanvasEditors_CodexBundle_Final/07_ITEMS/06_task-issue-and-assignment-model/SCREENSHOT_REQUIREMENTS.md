
# Screenshot requirements

## Minimum required evidence

- Task node with what/when/who details visible.
- Issue node with repository link path and alternative pure-description path.

## Expected artifact naming

Store screenshots under a stable path such as:

`artifacts/screenshots/i06/`

Recommended names:

- `01-primary-state.png`
- `02-secondary-state.png`
- `03-interaction-result.png`

Add more files when the item needs before/after or fallback-state evidence.

## Review reminder

A screenshot is only valid evidence if it clearly shows the requested behavior for this item.
