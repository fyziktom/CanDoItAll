Visual direction:

- full-width operational workspace;
- compact catalogue plus focused record workspace;
- restrained slate/blue BaseLib language;
- one horizontal stat strip instead of repeated fact cards;
- dominant next action and explicit blockers;
- stable dialog/page footers;
- no authority implied by automated analysis.
