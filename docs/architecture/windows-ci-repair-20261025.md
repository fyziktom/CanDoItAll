## Implementation boundaries

- Keep lifecycle test setup in the test-support project. Never reopen legacy mutation routes or turn conflicts into success.
- Seed historical schemas with their historical columns. Test upgrade behavior with the current model only after the relevant migration.
- Document public request, response, revision and recovery semantics through the existing typed OpenAPI transformers; preserve documentation enforcement.
- Fix the regular sandbox reservation race at prepublication admission: after another worker publishes the same source, return that source's saved reservation. Re-throw unrelated conflicts and never replay effects.
- Validate required prepared-launch payload members before hashing saved evidence, so malformed historical rows produce an explicit evidence failure instead of a null-reference exception.
- Update UI fixtures to use an interactive renderer and the actual disclosure controls. Preserve pending-operation recovery assertions.
- Keep import refusal for retained cancellation recovery. Cover both permitted terminal local history and refused completed cancellation evidence, preserving the original rows in either outcome.
- Await the HTTP continue decision in the oversized voice test, bounded by its existing request timeout. This avoids sending a large rejected body after the client's one-second handshake wait expires under Windows load; HTTP 413 and zero provider dispatch remain required.
- Exercise shared-object deletion with both a materialized agent catalog and concurrent first-use initialization. The cold case may retain the exact agent-access cleanup after a publication conflict; require that recorded failure and recover its original participant/recovery identity. Keep the single physical deletion and empty pending-cleanup assertions in both cases.
- Select the measured definition family in the capacity-test observer while allowing the other registered pools and lifecycle family to run. Keep family eligibility separate from aggregate pool eligibility, and retain explicit failure for malformed identities and incomplete observations. Observe connections from the extracted finite-operation context as well as Projects so terminal backend-exit evidence remains mandatory. Add a short real-child regression before the sustained workload, with bounded type/method diagnostics on child failure.
- Bound pressure observations by their phase and configured cadence. The old shared eight-minute deadline expired after one of two 60-second workers recovered: warning thresholds require a later cycle when timestamps fall just short of two minutes, complete metric frames arrive at the next cycle, and competing workers can need separate empty cycles. The repaired test retains the 30-minute cell deadline and all warning, contention, no-premature-recovery and exact-deletion assertions. Each wait now records its budget and names the phase on timeout.
- Do not assume fairness between workers whose schedules coincide. A full-row rerun showed one worker repeatedly winning the maintenance lock while its peer correctly remained contended. Once a worker proves recovery, stop it and require its peer to prove its own non-Busy Empty recovery. Retain both warning observations, the locked-state negative assertion, terminal backend-exit evidence and exactly one deleted receipt.
- In browser fixtures, submit the typed workspace-settings replacement with its captured expectation; check navigation failures against the actual absolute destination; wait for canvas publication and copy/cut acknowledgements before the next operation. Startup now initializes the account authority document, so the contended-save test verifies its empty user list and unchanged bytes while the mutation lock is held. Keep every rejection and persisted-state assertion.
- Give the starter-workflow smoke test an owned Responses endpoint and explicitly select its provider. Assert one actual request and the stored component's provider identity. Disable unrelated automatic run-narrative generation in the native-process fixture so its explicit manager conversation does not race that separate writer; production admission conflict behavior remains covered by its own integration tests.
- Components' delayed composer focus must belong to the opening that scheduled it and must preserve focus already moved by the user. The isolated repair covers create dialogs and inline notes, closed/replaced openings, and focus in another surface.
