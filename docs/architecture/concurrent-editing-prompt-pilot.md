## Architecture and composition

Keep native Prompt timestamp CAS and existing receipts. Pure merge owns scalar/set/keyed/
bounded-text algorithms without EF, Blazor or module references. Prompt adapters retain
domain normalization, lifecycle and typed raw draft values. Observation routes by dataset,
owner and exact key/catalog with bounded disposable subscriptions. Shared notification
presentation belongs to sibling Components; its lifetime must not depend on modal outlet.
No further partial-class cluster and no heavy AppComponents reference from Prompts.UI.

Gallery remains a bounded catalog with an independent full-size editor. Comparison is a
host-owned floating child overlay in the modal subtree, with typed fields, persistent
freshness status and stable Apply/Cancel actions. The editor instance and EditContext stay
alive. Comparison body owns scrolling; counts remain compact. Application proof targets
1920×1080; shared BaseLib overlay proof also covers small and medium viewports.
