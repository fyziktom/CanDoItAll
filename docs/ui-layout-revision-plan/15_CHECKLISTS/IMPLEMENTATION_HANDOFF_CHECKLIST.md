# Implementation Handoff Checklist

- Shell mode rules are documented
- Shared composition components are identified
- Migrated pages are listed
- Protected areas were not behaviorally changed
- Focus-workbench routes retain desktop navigation while docked
- Protected maximize mode was verified against the real viewport, not just by visual impression
- Shared radial-menu density, priority submenu labeling, and zoom floor were checked after the shell changes
- Tailwind output was rebuilt after UI markup/class changes
- Relevant tests were run
- Known risks or follow-ups are documented
- Remaining one-off layout debt is called out
