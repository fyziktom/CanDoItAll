# UI Support Scope

CanDoItAll currently targets large desktop screens for product UI design, implementation, and validation.

Large desktop is the supported layout profile for active development work. Small and medium screen responsive tuning is intentionally deferred until the desktop process, agent, project-structure, memory, and workspace flows stabilize.

Practical contributor rules:

- Validate core UI changes on a large desktop viewport first.
- Do not treat small or medium screen polish as an acceptance blocker unless a task explicitly changes the support scope.
- Avoid adding new mobile-specific layout branches during desktop-only feature work.
- Keep desktop layouts dense, readable, and operationally useful for repeated project delivery work.
