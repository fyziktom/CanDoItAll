# Original request

## User request 1

```text
Jsi senior C# Architektka.
Potřebuji, abys udělala revizi našeho kódu. Především se zaměř na nový Process modul. Nicméně zkontroluj i jestli nedublujeme věci napříč moduly. 
Zaměř se hlavně na obecné věci kolem architektury, možného přetěžování funkcí, moc dlouhých souborů, dlouhodobé údržby a vhodné úrovně modularity, možnosti unit testování a stabilizace funkcí, problémy s kanonicotou, problémy s výkoností, možné konflikty na db, apod.  

Na základě všech těch poznatků připrav detailní execution grade bundle včetně detailních subbundlů pro codex, aby vše správně opravil a otestoval a nic nevynechal nebo nepřeskočil. Vyplatí se mu dát i co pár subbundlů subbundle pro opětovnou revizi architektury, aby se zajistilo, že jde správným směrem a pokud zjistí, že ne, tak musí přiřdat pohotovostní subbundles kterými to prvně opraví a až pak bude pokračovat.
```

## User request 2

```text
Nálezy jsou to skvělé. Určitě to musíme opravit. Musíš to udělat znovu jako kompletní execution grade bundle včetně detailních subbundles a dát na výstup jako zip. Podívej se do našeho kódu tam můžeš vidět příklady bundles a co vše musí obsahovat. Určitě je dokážeš udělat ještě lepší než standardně máme. Pro codex je nutné mít přesné detailní instrukce.
Je také dobré tam vsadit vždy po pár subbundlech jeden další který donutí codex udělat mezirevizi architektury jestou jde správným směrem a pokud ne, tak si doplní subbundly kterýma to prvně opraví a až pak pokračuje dál.
Udělej nyní kompletní zip.
```
