# Codex stop rules

Stop immediately and open or execute corrective work if any of the following are true:

- the prepared-stage validator fails,
- gate A cannot prove canonical dependency meaning and pure validation,
- gate B cannot prove transaction safety, conflict handling, and stable child identity,
- gate C cannot prove healthier publication/runtime/query seams,
- gate D cannot prove ownership-aware consolidation, coherent workspace decomposition, and coherent schema hygiene,
- browser proof is missing for a UI-changing phase,
- the completed-stage validator fails.

## Always update when stopping

- `reviews/01-execution-report.md`
- `reviews/02-architecture-gate-memo-log.md`
- `plan/01-phase-plan.md` if a corrective subbundle is inserted
- `codex/MASTER_TASKS.json`
- `codex/TASKS.json`
