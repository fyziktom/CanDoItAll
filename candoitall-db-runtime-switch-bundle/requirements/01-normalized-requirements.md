## Explicit Non-Goals And Boundaries

- Per-user or per-session multi-tenant database selection is **not** a v1 requirement; the design assumes a local app-wide active profile.
- Running a mutable database directly on top of remote IPFS content is **not** a v1 requirement; IPFS is a transport/cache layer for snapshot materialization.
- Automatic Docker lifecycle orchestration from the UI is **not** required in v1; manual localhost/Docker-hosted PostgreSQL connection setup is sufficient.
- Cross-machine portable secret export is **not** guaranteed in v1 because encrypted secrets rely on the local control-plane key ring.
