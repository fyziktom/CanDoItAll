# Normalized Requirements

- `R001` The blocks explorer must expose the shared floating-window header controls for minimize, reset, hide, and drag instead of rendering as a chrome-less custom shell.
- `R002` The blocks explorer must keep a dark, readable visual treatment while using the shared floating-window chrome.
- `R003` Clicking a blocks explorer section must open its items in browser truth and the section stack must behave as an accordion when no search is active.
- `R004` Search results must stay scrollable within the visible blocks explorer window and visible items must keep readable labels and icons after scrolling.
- `R005` The final result must be proven with browser screenshots and targeted automated coverage, not only static markup assertions.
- `R006` Existing create actions, selected-source context, and search filtering behavior must continue working after the window and accordion changes.
